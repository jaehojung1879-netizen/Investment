## 3. 성과 분해의 단위와 재현 한계

본문 표의 순서는 `SPY 순 → SPY 총 → 가격가용 구성원 동일가중 → 금융/부동산 제외 → 가격 이력 → 완전 사례 → B2 선택 → B2 순`이다. 각 필터와 선택 사이 상호작용으로 기여도가 순서에 의존한다. 반대 순서의 분해나 인과적 독립 기여는 확보되지 않았다. 특히 −5.92는 동일가중과 가격가용 구성원 제한의 결합이며 순수 가중 효과라고 확정할 수 없다.

감사 보고의 연간 로그pp는 `+0.02 −5.92 −0.35 −0.03 −0.75 +4.12 −0.54`다. 반올림 항의 합은 −3.45다. 동결 순 CAGR에서 직접 확인한 값은 **−3.4460532011 로그pp/년**, 반올림 차이는 약 +0.003947이다. “잔차 0”의 정확한 독립 검증에는 미반올림 중간 집계가 필요하다.

선택 +4.12의 섹터 배분 +2.09 / 섹터 내 선택 +2.03 합계는 산술상 맞지만, 실제 바스켓 산출의 재현은 아니다. PARA 중립화 +3.64 역시 별도 감사 보고값이다. 중립화 방법(수익 0, 표본 제외, 대체 증권 등)은 제공되지 않아 임의로 정하지 않았다.

2024년은 동결 순수익 차이 −14.2398628898pp, 그 두 연수익의 로그차 −12.1063693285 로그pp다. 감사의 2024년 동일가중−SPY 약 −10.4는 별도 읽기이며, 전체 기간 분해 항과 더하지 않는다.

이 세 격차는 감사자가 제시한 제한된 처리의 범위다. “어떤 결함을 어떻게 처리해도” 결과가 같다고 일반화하지 않는다. 감사의 7/24 “마지막 정상 장부”라는 표현은 해당 민감도의 기준일 명칭이지 7/24 데이터 완전성의 인증이 아니다. 동결 완전 사례 수는 7/17 321, 7/24 284다.

현금/발생주의 순위상관 0.78은 원 집계 없이 재현하지 못했다. 명목 수익성 비중 40%(20%+20%)와 한 군 제거 시 25%가 되는 것은 고정 가중식에서 확인 가능하다. 이것만으로 실질적 단일 팩터 비중을 정확히 40%로 추정하거나 두 군 중 고유 우위를 정할 수 없다.

감사는 B2 추적오차 6.6%/년과 +2pp/년을 t=2로 확인하려면 약 44년이라는 설명도 제시했다. 입력 6.6을 가정하면 `(2×6.6/2)^2=43.56`은 산술적으로 맞다. 이는 IID·고정 신호·안정적 분산 등을 가정한 예시이고, 새 검정력 보정·유의성 검정·미래 44년의 보장이 아니다. 추적오차 원 시계열 자체는 미확보다.

현재 평가기간의 결손 18티커/1.88%, 결손 종목의 +145pp/년 초과수익이 있어야 격차가 뒤집힌다는 보고도 원 집계·반사실 모형이 미확보다. **2013~2026 전체의 212개 결손 퇴출 신원과 다른 기간/분모**다. 18이나 +145를 근거로 생존 편향·terminal payoff·US-MF-1 admission 문제를 면제하지 않는다.

## 5. 강제 5종목 분포와 비용 기준

보고된 1,000회는 B2 상위 20%에서 섹터당 최대 2종목으로 뽑은 무작위 5종목 진단이다. 비용 전 CAGR 평균 16.19%, 5~95백분위 3.2~29.2%, 실제 강제 B2 비용 전 13.9818%의 위치 약 40백분위다. 비용 후 실제 12.7741%의 백분위가 아니다. 무작위 비용 후 분포, B1 대응 분포, seed, 날짜별 재추출/유지·비중·회전율 처리의 정확한 코드가 없어 해당 부분은 재현 불가다.

동결 B2의 총 17.5808%→순 16.9511%, 강제 B2의 총 13.9818%→순 12.7741%는 확인했다. 순 차이 −4.1770128573 CAGR pp와 추가 비용 감소 차이 0.5780621787pp도 동결 집계로 확인했다. 리뷰의 약 −1.4 “분산 손실”, −2.2 “운”, −0.58 “추가 비용”은 이 CAGR 비교의 설명이다. 앞 두 항은 원 무작위 분포 없이 독립 검증된 인과효과가 아니며 앞의 연간 로그pp 분해와 섞지 않는다.
