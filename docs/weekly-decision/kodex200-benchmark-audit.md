# KODEX 200(069500.KS) 기준지수 원천 감사 — weekly-passive-first-v1

**결론:** replay-v16의 KODEX 200 시계열은 분배금을 **두 번** 반영했다. 검증 가능한 분배락 20건 중 19건에서
재현 시계열의 분배락일 성장률이 공식 분배 조정계수의 **제곱**이었다. 연수익률은 공식 대조 총수익률보다
2013–2026 매년 +1.11~+4.51%p 높다. 종목 시세에는 같은 결함이 6종목 표본에서 발견되지 않았다.

새로 계산한 결과는 없다. 모든 수치는 이미 커밋된 Phase C 무결성 감사 파일에서 읽었고
(`pipeline/weekly_history.benchmark_audit()`가 같은 계산을 매 빌드마다 재현한다), 봉인 파일은 수정하지 않았다.

## 1. 원천 비교

| 정의 | 출처 | 분배 처리 |

- 세금: 투자자 배당소득세 전(gross). ETF 보수는 시장가에 내재.
- 대칭성: 종목과 지수가 같은 레시피를 쓰지만, 이중 반영은 이 ETF의 세션 시세가 이미 분배 조정된 값이었기 때문에 지수 쪽에서만 생겼다(아래 4절).

## 4. 종목 쪽

Phase C의 사전 고정 6종목 표본 감사(`stock-price-integrity.json`)는 일반 현금배당의 이중 반영을
**발견하지 못했다**(`NOT_DETECTED_ON_ORDINARY_CASH_EVENTS_IN_THIS_SAMPLE`). 예외는 006800.KS(미래에셋증권)
2026-03-16 주식배당 이벤트로, 벤더 시세 변화에 현금 계수가 다시 곱해졌다. 260종목 전체는 대조되지 않았다.
따라서 replay-v16 기반 비교는 **지수 쪽이 부풀려진 방향으로** 기울어 있고, 종목 경로가 지수를 이기기 어렵게 만든다.

## 5. 주간 판단에 미치는 영향

- 판단의 기대초과는 봉인된 replay-v16 결과 원장(126거래일 초과수익)을 읽는다. 그 초과수익이 부풀려진 지수 대비라
  **수준은 종목에 불리하게 낮게** 잡힌다(연 1.1~4.5%p, 126거래일 기준 대략 그 절반).
- 순위 정렬 검정(top-minus-bottom t, rank IC)은 같은 날짜·지역의 모든 종목에 공통인 이동에 영향받지 않는다.
  현재 판단(한국 지수 100%)은 **정렬 미확인**(KR t=1.42) 때문이므로 이 결함으로 바뀌지 않는다.
- 봉인 원장은 수정하지 않는다. 결과 원장 자체의 재계산은 새 replay 세대(데이터 버전 변경)가 필요한 일이며 이 PR의 범위가 아니다.

## 6. 처리

1. **새 회계 버전**(`weekly-passive-first-v1-benchmark-basis-protocol.json`, 계산 전 커밋 `e46d76d8`): 069500.KS 보유분만
   Phase C 공식 대조 총수익 지수로 다시 평가한다. 판단·종목·비용·달력은 동일. 결과 파일 이름에 `-corrected-benchmark`.
2. 원래 replay-v16 결과 파일은 그대로 보존하고 사이트에서는 "원래 계산(분배 이중 반영)"으로만 접어서 보여 준다.
3. 사이트는 replay-v16 기준 CAGR을 헤드라인 카드로 쓰지 않고 "수익률 원천 미대조"를 표시한다. 수정 회계 결과도
   종목 쪽은 6종목 표본 감사뿐이므로 표로만 보여 주고 경로 간 순위를 매기지 않는다.
4. C2(+0.364%p, 21거래일 재현)는 양쪽 모두 부풀려진 지수를 들고 계산된 값이며, 결과를 본 뒤 만든 조합(기존 선택기 + 잔여 지수)이다.
   수정 회계 값이 어느 방향으로 나오든 검증된 우위로 해석하지 않는다.
5. 미국(SPY)은 이 감사 범위 밖이다(Phase C는 한국 전용).
