# KR Alpha Atlas Phase C — 개발 증거와 투자 지명의 해석

이 문서는 [동결된 Phase C 명세](../research_specs/kr-alpha-atlas-phase-c-v1.json)와
[결과 스키마](../research_specs/kr-alpha-atlas-phase-c-result-schema-v1.json)의 기존 필드를
해석하는 안내다. 가설·기간·문턱·기준모형·판정·실행 절차를 추가하거나 변경하지 않는다.
[실행 전 검토 안내](kr-alpha-atlas-phase-c-readiness-ko.md)의 승인·무결성 조건도 그대로 적용된다.
아래 예시는 해석 규칙이며, 실제 한국 과거 수익률을 계산하거나 관측한 결과가 아니다.

## 다섯 가지 질문을 따로 읽는다

최상위 `verdicts`는 전체 판정 사슬의 결론이다. 그 값 하나로 개별 관계, 추가 정보,
조건부 증거, 경제 진단의 결과를 대신해서는 안 된다. 기계 판독 결과에는 각 층위가
별도로 보존되므로 한국어 보고서도 다음 다섯 항목을 각각 설명한다.

아래 경로는 결과 JSON의 루트를 기준으로 한다. 중괄호는 실제 키를 대입한다.
`feature_horizon`은 특징 ID와 `_H126` 등의 조합, `horizon`은 `126` 등의 문자열,
`comparison`은 `ADD_A_H126` 등의 등록 비교, `interaction`은 등록된 X1–X6 ID다.
`hypothesis`는 실행된 특징–기간 키 또는 상호작용 ID, `policy`는 등록된 경제 정책 키다.

| 질문 | 기계 판독 결과 경로 | 한국어 해석 |
| --- | --- | --- |
| 1. 개별 예측 관계 | `level1.{feature_horizon}`, `level1.{feature_horizon}.statistics`, `level1.{feature_horizon}.stability` | 순위 IC, 업종 내 IC, 삼분위 차이와 안정성을 보고한다. H21·H126 항목의 `adjustedP`도 함께 읽는다. 개별 상관만으로 추가 정보나 투자 가능성을 주장하지 않는다. 기술통계 기간에는 보정 p값이 없다. |
| 2. B4 이후의 추가 예측 정보 | `level2.{horizon}.comparisons.{comparison}`, `residualInformation.{feature_horizon}`, `trainingOnlyRedundancy.{horizon}` | 같은 관측치의 예측 오차·순위 스프레드 개선, 가족 추가·제거, B4 잔차 정보와 훈련 중 중복 관계를 함께 읽는다. |
| 3. 조건부 개발 증거 | `level3.{interaction}`, `interactionVerdicts.{interaction}` | 상태별 관계, 등록 대조군 대비 차이, 보정 p값과 원천·추론 상태를 보고한다. 상호작용의 통계 결과와 전체 투자 지명 판정을 구분한다. |
| 4. 미검증 벤치마크 아래의 경제 진단 | `level4.{hypothesis}.policies.{policy}`, `level4.{hypothesis}.benchmarkClaimStatus` | 등록 조건을 통과해 실행된 정책의 비용·위험·용량·기여도를 진단한다. 숫자가 존재해도 검증된 벤치마크 대비 알파가 되지는 않는다. |
| 5. 최종 투자 후보 지명 적격성 | `verdicts.{feature}.verdict`, `prospectiveNominations`, `benchmarkIntegrity` | 전체 등록 조건과 벤치마크 무결성 게이트를 적용한다. 현재 등록에서는 긍정적인 최종 지명을 할 수 없다. |

정식 실행의 증거 분류는 `EXPLORATORY_DEVELOPMENT_ON_OUTCOME_EXPOSED_KR_HISTORY`다.
이미 노출된 한국 역사의 관계를 **개발 증거**로 해석하며, 시간 순서대로 나눈 평가도 독립 확증은
아니다. `SYNTHETIC_SOFTWARE_VALIDATION_ONLY` 결과는 소프트웨어 시험이며 투자 증거가 아니다.

## 긍정·부정·평가 불가를 보존한다

개별 특징의 긍정적인 개발 관계는 등록된 주 기간의 방향, 가족 내 BY q=.10,
보정된 SN 구간 하한과 안정성 조건을 함께 통과해야 후속 단계로 진행한다.
H21·H126의 등록 추론을 사용하며 H63·H252는 기술통계로 남긴다. IC나 한 기간의
유리한 숫자만 골라 전체 조건을 통과했다고 쓰지 않는다.

B4 대비 추가 정보는 가족 추가 비교의 `pairedMseImprovement`와
`pairedRankWeightedSpreadImprovement`, `adjustedP`, `positive`를 함께 읽는다.
가족 비교 30개 전체의 Holm .05와 기존 잔차 조건을 유지한다. 한 가족의 개선을 그 가족의
모든 특징이 각자 고유한 정보를 제공한다는 증거로 확대하지 않는다. 해당 특징의
`residualInformation`과 훈련 중 중복 지도도 공개한다. 조건부 기울기는 등록된 기술적
연관성 진단이며 별도의 보정된 발견으로 승격하지 않는다.

비교마다 `commonObservations`, `sampleSha256`, `identicalEvaluationPopulation`,
`preCommonBase`, `preCommonAlternative`를 함께 공개한다. B4 완전 관측률 약 44.3%는
나머지 관측치를 전부 삭제하라는 뜻이 아니다. 훈련에서만 학습한 결측 대체·척도와 고정된
결측 지표를 사용하며, 양쪽 비교는 동일한 결과 유효 관측치에서 평가한다. 공통 표본이
부족하면 평가 불가로 설명하고, 표본 차이를 예측력 차이로 해석하지 않는다.

조건부 가설은 정확히 X1–X6과 등록 대조군만 읽는다. 여섯 슬롯 전체의 Holm .05를 유지하고
차단 슬롯도 p=1의 보정 자리를 보존한다. X4는 투자자별 흐름 원천이 없어 차단되며 OHLCV로
대체하지 않는다. X6의 시장 추세·변동성별 부호는 기술통계다. CPI·실업·인플레이션/성장 상태의
관계가 검증됐다고 해석하지 않는다. X3의 기존 시험된 구성요소만으로 신규 후보 지명 조건을
충족시킬 수 없다. 조건부 통계는 `level3`에 남고 전체 지명 사슬은 `interactionVerdicts`에 남는다.

| 등록된 전체 판정 | 보존해야 할 해석 |
| --- | --- |
| `NO_DEVELOPMENT_EVIDENCE` | 적용 가능한 등록 조건에서 개발 증거를 얻지 못했다. 모든 미래 관계가 없다는 증명은 아니다. |
| `UNSTABLE` | 개별 관계가 보이더라도 등록 안정성 조건을 통과하지 못했다. 방향과 연도·전후반 차이를 남긴다. |
| `REDUNDANT` | 등록된 추가 정보 조건을 충족하지 못했다. 개별 관계의 숫자를 삭제하지 않으며, 완전한 동등성의 증명으로 확대하지 않는다. |
| `NOT_ECONOMIC` | 실행 가능한 등록 경제 진단이 순기회 또는 종목 선택 기여 조건을 통과하지 못했다. 비용·업종·현금/패시브 효과와 미검증 벤치마크 한계를 함께 남긴다. |
| `BLOCKED` | 원천·결과 무결성·표본·추론·지명 조건 중 무엇이 평가를 막았는지 해당 층위의 필드로 설명한다. 관계가 없다는 결론으로 대체하지 않는다. |
| `INDEPENDENT_DEVELOPMENT_SUPPORT` | 등록된 전체 사슬을 통과한 추가적 개발 지원을 뜻한다. 독립적인 미래 확증을 뜻하지 않으며 현재 벤치마크 게이트에서는 도달할 수 없다. |

`level4Status=NOT_TRIGGERED`이면 경제 진단은 실행되지 않았다. 그 자체를 경제성 실패로
쓰지 않는다. `EXECUTED`여도 정책의 `status=BLOCKED`이면 숫자 생성이 가능한 정상 평가가
아니다. 미관측 종료 지급액을 0이나 마지막 가격으로 채우지 않고, 선택 종목 또는 필요한 업종
참조가 무효면 해당 포트폴리오 비교를 차단한다. 손실 표본은 `labels.attrition`의 종목·기간·연도·
업종별 수와 게이트 전후 차이로 설명한다.

## 벤치마크 차단의 정확한 범위

069500.KS는 유지되며 `benchmarkIntegrity.claimGate=BLOCKED_UNVERIFIED`를 우회하지 않는다.
호환되는 권위 있는 외부 대조 원천이 고정되지 않았으므로 절대적인 벤치마크 상대 경제 성과,
확인된 투자 알파, 긍정적인 최종 투자 후보 지명은 차단된다. 이 등록의 한 번의 실행 중
다른 벤치마크로 바꾸거나 대조 자료를 추가해 게이트를 해제하지 않는다.

같은 날짜·진입·청산 기간·표본에서 모든 종목에 같은 벤치마크 수익률을 빼는 연산은
종목 순위와 상·하위 차이를 바꾸지 않는다. 날짜 내 중심화한 모형 목표도 이 공통 상수의
영향을 제거한다. 따라서 다른 데이터·표본·추론 조건이 유효하면 해당 개별 관계와 추가 정보는
그 한계를 밝힌 개발 증거로 보존할 수 있다. 이 성질이 가격·기업행동·결측 문제까지 해결하거나
`topExcess`, 절대 초과수익, 복리 성과를 검증하는 것은 아니다.

경제 정책의 `status=DEVELOPMENT_DIAGNOSTIC`은 계산 가능한 개발 진단이라는 뜻이다.
별도 `claimStatus`와 `benchmarkClaimStatus`의 차단을 반드시 함께 표기한다.
총수익·순수익·비용·거래회전·낙폭·하방 위험·용량을 숨기지 않되 검증된 알파로 부르지 않는다.
A–G 기여에서 업종 배분 B와 개별 종목 선택 C를 구분하고, D 위험 설명을 별도 수익 기여로
더하지 않는다. 변동성 차이에서 생긴 복리 효과도 종목 선택의 증거로 바꾸지 않는다.

예를 들어 개별 관계·안정성·가족 추가·잔차 조건을 통과하고 실행 가능한 순경제 진단도
긍정적이라면, 보고서는 **“개별 및 추가적 개발 증거는 관측됐고 경제 진단도 긍정적이나,
벤치마크 외부 대조 미해결로 최종 투자 후보 지명은 BLOCKED”**라고 쓴다. 기존 `level1`,
`level2`, `residualInformation`, 필요한 `level3`, `level4` 수치를 모두 남긴다.
반대로 비용 후 기회가 사라진 경우에는 `NOT_ECONOMIC`과 비용 진단을 남기며,
벤치마크가 미검증이라는 이유로 그 부정적 진단을 일반적인 차단 문구로 덮지 않는다.
두 경우 모두 확인된 투자 알파라는 주장을 할 수 없다.

현재 등록으로 생성되는 결과의 `prospectiveNominations`는 빈 배열로 유지돼야 한다.
이를 모든 특징의 예측 관계가 없었다는
뜻으로 해석하지 않는다. 긍정·부정·불안정·중복·평가 불가를 층위별로 공개하고 Phase D에서
한국 역사 연구를 닫는다. 후속 확증은 사전 기록한 실제 미래 신호와 결과로만 가능하다.
