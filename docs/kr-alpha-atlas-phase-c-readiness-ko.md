# KR Alpha Atlas Phase C — 실행 전 검토 안내

이 PR은 한 번의 최종 한국 주식 **개발 연구**를 실행할 소프트웨어와 사전등록을 구현한다.
실제 과거 수익률·라벨·모델·IC·포트폴리오는 계산하지 않는다. 합성 시장 결과는 투자 성과가 아니다.
2026-09-14까지 이미 노출된 한국 역사는 재분할해도 독립 확증이 되지 않는다.

## 측정과 판정

Phase B의 38개 신규 후보를 가족별 등록 기간에서 73회 평가한다. H21·H126의 51개 항목에는
기존 달력 시간 SN 추론을 사용하고, H63·H252의 22개 항목은 기술통계로 남긴다.
B0–B4의 20개 기준모형 항목, FULL 4개, 가족 추가 15개·제거 15개 비교, 잔차·조건부 기울기
각 73개를 같은 실행에서 산출한다. 6개 조건부 가설 중 X4는 투자자 흐름 원천 부재로 차단하고,
X6의 상태별 차이는 시장 추세·변동성 기술통계다. CPI·노동시장·인플레이션 가설은 시험하지 않는다.

개별 상관, B4 이후의 추가 정보, 안정성, 업종 효과, 개별 종목 효과, 위험 노출, 비용과 복리 효과를
구분한다. 계열 내 BY q=.10, 가족 비교 30개 전체의 Holm .05, 조건부 가설 6개 전체의 Holm .05를
고정한다. 차단 항목도 p=1 자리로 남긴다. SN p값은 Brownian bridge 극한분포에 근거한 점근적
개발 p값이며, 작은 꼬리 확률의 유한표본 보정이 검증됐다고 주장하지 않는다. 긍정 판정에는 기존
보정 SN 구간의 하한도 0보다 커야 한다. 전년도까지 성숙한 결과만 연간 확대 훈련에 사용하며,
평가연도 최초 신호보다 21거래일 앞선 절단점 이전에 종료된 목표만 허용한다. H252/2016은
과거 신호일 99개로 최소 104개에 미달하고, H252/2026은 성숙한 평가일이 없어 적합하지 않는다.
계획 가능한 예측·전처리 적합 상한은 **574회**다.

B4 완전 관측률 약 44.3% 때문에 나머지를 일괄 삭제하지 않는다. 훈련 자료에서만 결측 중앙값과
척도를 학습하고 열별 결측 지표를 고정한다. 훈련에서 전부 결측인 열은 평가에서도 비활성이다.
같은 비교의 양쪽 모형은 동일한 결과 유효 관측치에서 계산하고 표본 수·신원 해시를 공개한다.

거래대금은 `PROXY_ASTRADED_CLOSE_X_VOLUME`로 고정하며 공식 ACC_TRDVAL와 같다고 주장하지 않는다.
22개 종료 종목의 경제적 불완전성 및 연구 기간 내 8개 종료 사건을 보존한다. 기존 v4의 종목별
배당·터미널 완전성 정책을 대칭적으로 적용한다. 불명확한 지급액은 0이나 마지막 가격으로 만들지
않는다. 종목 선택 후 선택 종목 또는 필요한 업종 참조가 무효면 포트폴리오 비교 전체가 차단된다.
연도·업종·종목·기간별 손실 표본과 게이트 전후 차이를 결과에 기록한다.

경제 평가에는 동일 가중 상위 그룹 진단과 최대 5종목·업종당 최대 2종목·자리당 20%를 사용한다.
미사용 자리는 현금과 069500.KS 두 별도 정책으로 평가하며, 0종목도 허용한다. 자금 5천만원,
각 주문은 과거 60거래일 중간 프록시 거래대금의 1% 이하다. 수수료 5bp·반 스프레드 6bp를
적용하고 매도세는 저장소의 날짜별 30/25/23/20/18/15/20bp 일정을 따른다. 벤치마크 왕복 비용
각 15bp는 가정이다. A/B/C/E/F/G 산술 기여는 합계가 일치해야 하며, D 위험 회귀는 C와 중복되는
설명이지 추가 수익 기여가 아니다. 개별 종목 선택은 C만 인용할 수 있고 복리 이익을 선택 알파로
부르지 않는다.

20% 자리는 매수 비용을 포함한 현금 예산이며 실제 자산 비중은 예산/(1+매수 비용률)이다.
벤치마크·패시브 대체도 같은 방식으로 비용을 충당해 차입을 만들지 않는다. 이후 용량 검사는
직전 순수익을 반영한 순자산으로 계산한다. 순자산이 불명확해지면 후속 블록도 차단한다.
진입 판단에는 신호일 비용만 쓰고 실제 매도에는 매도일의 유효 세율을 적용한다.

069500.KS 외부 권위 자료와의 대조는 미해결이다. 이 등록에는 대조 원천이 고정돼 있지 않으므로
절대 경제 성과·실제 투자 알파·긍정적 후보 지명은 차단 상태다. 순위·날짜 내 차이·조건부로 유효한
개발 관계는 별도로 보존한다. 후보 0개는 유효한 결론이며 한국 과거 탐색의 재실행 사유가 아니다.

## 운영 준비 및 남은 검증

원본 아카이브 ID 11157875265의 이름, 실행 ID, ZIP SHA-256, 비만료 상태를 GitHub API로 확인했다.
현재 셸의 서명 URL 접근은 403이며 GitHub 연결이 반환한 ZIP 참조도 워크스페이스로 내려받지
못했다. 원본 전체 바이트 검증은 완료했다고 주장하지 않는다. 공식 거래대금 파일은 이 연구의
선택 입력이 아니며, 출처 참조로만 보존한다. **선택 입력은 Phase B가 실제 측정한 Git 고정 프록시
스냅샷**이다. 명세의 정확한 입력 신원·회계·유니버스·가격 객체·바·주식 수·업종 소스 해시를
검증하여 다시 읽으며, 다른 파일을 원본 아카이브라고 부르거나 재수집하지 않는다.
실제 Git 객체 신원과 재생 매니페스트 구조는 결과 접근 없이 검증한다. 선택 스냅샷의 전체 체크섬,
PIT 행렬 해시 재현 및 준비 조건은 승인된 실행에서도 반드시 잠금 전에 통과해야 한다.

예상 공식 예산: 입력·특징 준비 30분, 연구 계산 45분, 기록 여유 15분. 프로세스 전체 상한 90분,
메모리 8GiB, 작업자·수치 스레드 각 1. 잔차 투영·조건부 기울기는 각각 최대 52,122회,
경제 정책 최대 492개, 부트스트랩 499회/실행 정책(총 상한 245,508회)이다. 초과하면 명시적 실패이며
가설을 몰래 빼거나 계산량을 자동 축소하지 않는다. 실제 전체 입력의 성능 추정은 아직 확정값이
아니며, 결과 접근 없는 준비 중 한도를 넘으면 잠금 생성 전에 차단한다.

합성 시험 A–N은 실제 라벨·통계·모형·경제·판정·쓰기 함수를 호출한다. 알려진 신호, 잡음, 중복,
독립 추가 정보, 비용으로 사라지는 기회, 업종 편향, 결과 관련 결측, 불명확한 종료 지급,
불공정 표본, 미래 공시, 상태별 부호 반전, 원천 차단, 정규 JSON 바이트 결정성, 잠금 전후 실패를
시험한다. 별도 시험에서 정확한 85,680행 규모, 전처리 결측, 전부 차단된 상호작용, 0종목,
무가격 종목, 출력 스키마, 불변 쓰기, 소스 체크섬, 적합·메모리 상한도 검증한다.
