# weekly-passive-first-v1 — 주간 지역별 판단 규칙 (사전 고정)

**상태:** `EXPLORATORY_WEEKLY_DECISION` · 승격 불가 · `liveValidated=false`
**기계 판독 사양:** [`docs/weekly-decision/weekly-passive-first-v1.json`](weekly-decision/weekly-passive-first-v1.json)

사양·결과 파일은 `docs/weekly-decision/`에 둔다. `research_specs/`와 `docs/results/`는 봉인된
kr-alpha-atlas Phase C 등록이 폴더 전체를 보호 해시로 고정하므로 새 파일을 추가하면 그 등록이 깨진다.
사양은 커밋 `001f1385`에서 `research_specs/`에 먼저 푸시됐고, 바이트 그대로 이동했다(결과의 `specSha256`로 대조).

이 문서와 사양 파일은 이 규칙의 과거 재현 결과(P1·C2)를 계산하기 **전에** 커밋되었다.
다만 작성자는 기존 replay-v16 연구 결과 전부와, 2026-10-10 전체 원장 기준 운영 보정에서
한국·미국 모두 알파 순위의 수익 정렬이 확인되지 않는다는 사실(KR t=1.42, US t=0.61)을 이미 보았다.
따라서 과거 재현은 결과에 노출된 **기술적(descriptive) 증거**이며 확증이 아니다.

## 질문

매주 한국과 미국 각각에 대해: 지역 지수(KR `069500.KS` KODEX 200, US `SPY`)를 그대로 들고 있을지,
아니면 비용을 내고도 지수보다 유리할 근거가 있는 개별 종목을 최대 5개 담을지.

## 규칙

1. 후보: 각 지역의 production 장기 리서치 슬리브(`longterm.build` picks). 지역 간 비교·통합·환율 입력 없음.
2. 우위 추정: production `historical_calibration.calibrate`(126거래일, 비용조정, 유니버스 캐리 제거, 순위 정렬 검증)의
   해당 지역 × 알파 백분위 버킷 값. 버킷이 `usable`일 때만 사용하고, 아니면 **추정 불가(0 아님)**.
3. 전환 비용: 종목 왕복(연도별 실제 한국 증권거래세 포함, `benchmark_alpha.REALISTIC_COSTS`) + 지수 ETF 왕복
   (국내 주식형 ETF는 증권거래세 면제로 0bp).
4. 순우위 = 우위 추정 − 전환 비용. 순우위 > 0, 진입/리서치 상태 배율 > 0, 하방위험 측정 가능해야 후보 자격.
5. 순위: (순우위 + 기존 보유 유지 크레딧) ÷ 하방위험 × 상태 배율. 유지 크레딧은 자격 판정 **뒤**에만 적용.
6. 선택: production `select_portfolio_by_scores`, 최대 5종목, 섹터당 2종목, 최소 0종목.
7. 비중: 종목당 15%(`config.json longterm.maxNameWeight`), 나머지 전부 지역 지수 ETF. **합계 항상 100%, 현금 목표 없음.**
8. 데이터가 그 지역의 마지막 완료 세션보다 오래되면 새 판단을 내지 않고 직전 유효 판단을 실제 기준일과 함께 유지.
9. 판단 영수증은 (정책 버전, 지역, 기준일)로 식별되고 추가만 가능. 같은 식별자의 다른 내용은 거부.

## 과거 비교 프로토콜 (한 번, 사전 고정)

| 경로 | 정의 |
|---|---|
| P0 | 지역 지수 ETF 100%, 최초 1회 매수 후 보유 |
| P1 | 위 규칙을 기존 21거래일 고정 앵커 155개 블록에 적용(각 앵커 시점까지 만기된 결과만으로 재보정) |
| C1 | 봉인된 지역별 단독 CHAMPION 경로(현금 잔여), 같은 비용표로 재비용 처리. 기존 증거 |
| C2 | C1의 비중 그대로, 잔여를 현금 대신 지수 ETF로 보유. 대체 자산 효과만 보는 기술 비교 |

- 실제 운영은 주간 판단이지만, 동결된 replay 원장과 평가 달력이 21거래일 앵커로만 존재하므로 재현은 21거래일마다 재판단한다.
- 평가는 production `replay_valuation`을 그대로 사용. 가격이 없는 보유 종목은 0·마지막 가격으로 메우지 않고 경로를 `PARTIAL`로 표시.
- 초기 자본 5,000만 원. 모든 경로에 같은 비용표, 같은 세션.
- 미국 경로는 계산하지만 헤드라인 불가: 퇴출된 S&P 500 종목 324개 중 212개의 가격 이력이 없어 생존편향(`SURVIVORSHIP_BIASED_PARTIAL`).
- 한국 경로는 replay-v16 가격 정의(주식·지수 동일 레시피)라 내부 비교는 일관되나, Phase C 대조에서 이 레시피의 KODEX 200 연수익률이
  정정된 총수익률보다 매년 +1.11~+4.51%p 높았다. 절대 수익률은 과대일 수 있고 `BENCHMARK_DEFINITION_REPLAY_V16_NOT_RECONCILED`로 표기한다.
- 금지: 재현 결과로 비중·종목 수·기간·비용·문턱 선택, 같은 id로 규칙을 바꾼 재실행, 어떤 경로든 "검증됨"·"사전에 알 수 있었던 최고"로 표시.
