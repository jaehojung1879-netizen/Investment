## 종목 순위 진단

진입은 신호 다음 미국 세션 종가, 종료는 진입+H세션 종가다. 같은 완전 사례 전체에 모든 점수·제거 조합을 적용한다. 미래 종가가 하나라도 없으면 해당 날짜 전체가 미해결이다. 만기 미도래는 제외 사유로 따로 센다. 이 실행에서는 만기 도래 표본에 미해결 종가가 없었다.

|---|---:|---:|---:|---:|---:|---:|---:|
| 63 | 165 | 11 | 0.0138 | -0.0001 | -0.0139 | -0.39pp | +0.11pp |
| 126 | 152 | 24 | 0.0511 | 0.0017 | -0.0494 | -0.02pp | +0.56pp |
| 252 | 126 | 50 | 0.0730 | -0.0268 | -0.0998 | -2.93pp | -2.97pp |

IC는 날짜별 Spearman 상관의 단순 평균, 스프레드는 상위 20%−하위 20%의 해당 H세션 수익률 차이다. 스프레드는 연율화·거래비용 차감값이 아니다. 주간 표본은 중첩되므로 독립 표본 수나 통계적 유의성으로 읽지 않는다. H별 상위 집단−SPY 및 개별 팩터 진단은 JSON에 모두 있다.

## 왜 SPY보다 못했나 — 감사의 순차 성과 분해

단위는 **연간 로그수익률 차이 × 100(로그pp/년)**다. `L(P)=100×ln(1+CAGR(P))`이고, 같은 856세션 구간에서 `L(B2 순)−L(SPY 순)=−3.446053`이다. 이는 동결 CAGR 차이 **−4.100443pp**와 같은 두 끝점의 다른 표현이다. CAGR pp와 로그pp를 혼용해 더하지 않는다.

| 순서 | SPY 순수익에서 B2 순수익으로의 전환 | 로그pp/년 | 확인 범위 |
|---|---|---:|---|
| 1 | SPY 최초 매수비용 제거 → SPY 총수익 | +0.02 | 동결 총·순 CAGR로 +0.023542 확인 |
| 2 | 가격이 있는 당시 구성원의 동일가중 바스켓으로 변경 | −5.92 | 감사 보고; 중간 바스켓 미확보 |
| 3 | 금융·부동산 제외 | −0.35 | 감사 보고 |
| 4 | 가격 이력 조건 적용 | −0.03 | 감사 보고 |
| 5 | 완전 사례 필터 적용 | −0.75 | 감사 보고 |
| 6 | 자기 완전 사례 동일가중 바스켓 → B2 상위 집단 선택 | +4.12 | 감사 보고 |
| 7 | B2 거래비용 차감 | −0.54 | 동결 총·순 CAGR로 −0.536969 확인 |
| 끝점 차이 | B2 순수익 − SPY 순수익 | **−3.446053** | 동결 집계 산술 확인 |

감사에서 가장 큰 음의 항은 동일가중 바스켓 전환(−5.92)이고, 추가 유니버스 필터 세 항의 보고값 합은 −1.13이다. 다만 −5.92는 **동일가중 방식과 가격가용 구성원 집합을 함께 바꾼 결합 효과**다. 공식 S&P500 동일가중 지수나 순수한 가중 방식의 인과효과로 간주하지 않는다. 각 단계의 정확한 바스켓·재조정 정의와 전체 정밀도 중간 집계는 미확보다.

**이 분해는 순서 의존적이다.** 가중 방식, 유니버스, 섹터 및 선택 규칙이 상호작용하므로 필터 순서를 바꾸면 기여도도 바뀔 수 있다. 유일한 원인 분해, Shapley 기여도, 팩터 알파나 새로운 사전등록 결과가 아니다. 표의 반올림 항 합은 −3.45로, 확인한 끝점 −3.446053과 약 0.003947 로그pp 차이가 난다. 감사의 “잔차 0”은 미반올림 중간 계산에 관한 보고이며, 현재 확보한 반올림 숫자만으로 독립 재현했다고 주장하지 않는다.

- **B2 선택의 해석:** 감사는 자기 동일가중 완전 사례 바스켓 대비 +4.12를 섹터 배분 +2.09, 섹터 내 선택 +2.03으로 나눴다. PARA를 중립화하면 +3.64라고 보고했다. 모두 사후 감사 보고값이며 원 계산물 없이 확증된 독립 선택 알파로 승격하지 않는다. 그래도 SPY 하회를 곧바로 “자기 유니버스 안에서도 선택이 실패했다”로 설명했던 해석은 수정한다.
- **IC와 바스켓 성과:** B1 대비 B2 IC 개선이 없다는 동결 사실은 유지한다. 다만 감사의 H63 5분위 평균은 최하위 4.08%, 최상위 4.19%, 전체 평균 3.53%로 U자형이다. 이는 H63 비용 전 수익의 보고값이며 연율화 수치가 아니다. 단조 순위 IC와 상위 바스켓 수익은 다른 읽기다. 분위별 원 집계는 미확보다.
- **집중과 비용:** 강제 5종목은 아래 감사 비교에서도 진단일 뿐이다. B2 비용 전 CAGR 17.58%도 SPY 21.08%보다 낮지만, 양자의 차이는 선택만의 효과가 아니다. B2 비용 항 −0.54 로그pp와 위 표의 다른 항을 구분한다.
- **경제적 관문과 판정:** 검증된 PIT 기대 순초과수익 추정이 없어 관문 전략은 여전히 측정 불가다. 원 경제적 결론은 **NOT BEATEN**, S&P500 전체·다른 국면·실전 우월성으로의 일반화는 **INCONCLUSIVE**다.

### 강제 5종목 무작위 비교 — 사후 감사 보고

감사는 **B2 상위 20% 안에서, 섹터당 2종목 제한으로 5종목**을 추출한 1,000회 분포를 보고했다. 전체 S&P500에서 뽑은 비교도, 1,000개의 독립 OOS 기간도 아니다. 난수 seed·추출 시점·주간 재추출/유지 방식·원 출력은 미확보다.

| 읽기 | 비용 전 CAGR | 비용 후 CAGR |
|---|---:|---:|
| 동결 B2 상위 20% | 17.58% | 16.95% |
| 감사 무작위 5종목 평균 | 16.19% | 미제공 |
| 감사 무작위 5~95 백분위 구간 | 3.2~29.2% | 미제공 |
| 동결 실제 B2 강제 5종목 | 13.98% | 12.77% |
| 감사 분포에서 실제 전략 백분위 | 약 40 | **확인 불가** |

**40백분위는 비용 전 실제 13.98%의 위치**다. 비용 후 12.77%를 비용 전 분포와 비교한 백분위가 아니다. 무작위 비용 후 분포는 제공되지 않아 계산했다고 주장하지 않는다. B1 강제 5종목의 대응 무작위 분포도 미제공이다.

감사의 −4.18 CAGR pp 분해는 `상위 20% 총 17.58 → 무작위 평균 총 16.19` 약 −1.4, `그 평균 → 실제 강제 총 13.98` 약 −2.2, 추가 비용 약 −0.58이다. 동결 값에서 확인한 순 CAGR 차이는 −4.177013pp, 추가 비용 감소 차이는 0.578062pp다. 앞의 SPY 분해와 달리 **여기는 CAGR pp**다. “분산 손실/운”은 감사의 해석명이며, 평균의 추출 정의와 난수 원자료 없이 순수한 인과효과·통계적 유의성으로 확증하지 않는다. 이 비교를 근거로 종목 수나 선택 규칙을 바꾸지 않았다.

### 별도 감사 발견 C — PARA 정체성과 개명 매핑

감사는 `PARA` 가격 패널이 Paramount Global과 다른 증권의 시계열이라고 지적했다(약 10→0.00012, 하루 +97%와 즉시 되돌림 반복). 감사의 영향 보고는 B2 포트폴리오 0, B1 약 ±0.03 CAGR pp이며 유니버스·IC에는 영향이 있다는 것이다. **해당 패널의 공급자 증권 ID·발행사 증거와 중립화 계산물은 미확보**다. 정체성 검증 문제로 공개하며 어느 다른 증권인지 임의로 확정하지 않는다. 미해결 정체성 문제가 무해하거나 신규 데이터 admission을 통과한 것으로 보지 않는다.

감사는 ABC→COR, CDAY→DAY를 퇴출이 아닌 개명 매핑 누락으로 구분했다. 고정 신원 메타데이터에서 ABC의 사용 가능한 개명 매핑은 없고, CDAY는 `successor=DAY`가 있어도 `pricedBy=null`이어서 실행기의 해결 매핑에서 빠진다. 개명 관계 지적과 실제 시계열 접합·권리 연속성 검증은 별개다. 이번에는 매핑·유니버스·가격을 고치거나 이어 붙이지 않았으며, 결손 또는 지수 퇴출을 상장폐지·0원 정산으로 바꾸지 않았다.

## 계산하지 않은 항목과 한계

- 경제적 관문 B3 두 전략: `NOT_ESTIMABLE — NO_SCORE_SPECIFIC_PIT_EXPECTED_NET_EXCESS`.
- `B2_PLUS_VALUE`: 역사 주가·주식수 기준의 독립 검증이 부족하여 미측정. 현재 매수 후보: `CURRENT_CANDIDATES_NOT_VERIFIED`, 후보 목록 없음.
- 212개 퇴출 신원의 가격 결손 및 미검증 terminal payoff를 해소하지 않았다. PR #241의 복구 가격이나 #244 파일럿 자료를 편입하지 않았다. 지수 퇴출을 상장폐지로 간주하거나 마지막 가격으로 강제 청산하지 않았다.
- 구성원은 과거 Git 스냅샷의 관측일 기준이며 공식 편입·퇴출 효력일을 입증하는 완전한 PIT 자료가 아니다. 적용 스냅샷 나이는 1~767일이다. 섹터도 그 스냅샷 또는 앞선 관측만 사용한다.
- 공시는 max(availableFrom, acceptedDate) 다음 날부터 사용하고 보고기간말 180일 초과는 결손 처리한다. 동일 회계연도·단계는 원래의 최초 공개본을 유지한다. 누적 현금흐름은 기존 FY+당해 누적−전년 동기 누적 방식을 재사용한다.
- 레버리지 지표의 기존 이름 `debtToEquity`는 **총부채(liabilities)/양수 자기자본**이다. 이자부 차입금 비율로 오해하지 않는다. 음수·0 자기자본이나 결손을 0으로 대체하지 않는다.

**후속 작업의 경계:** 재무상태표 결손·PARA 신원·개명 매핑의 교정과 과거 CIK 연결을 통한 기간 확장은 별도 소유자 검토 범위다. 이 문서 수정이 자동 교정, 신규 가격 admission, 표본 확대나 재실행을 승인하지 않는다. 퇴출 가격·terminal economics·원가격 총수익 대조의 제약도 그대로이며, 현재 수치를 실전 우월성으로 전환하거나 결과에 맞춰 점수를 튜닝하지 않는다.

## 재현과 무결성

기준 main `c14080cf9266e5d2b1b6babae8ae3c018c54b93c`; #241/#242/#243 병합 확인. #244는 변경·병합하지 않았다. 실제 결과를 읽기 전 계산기·방법을 고정한 커밋은 **`c124bf6`**이다. 이전 실행 거부 결과는 이번 명시적 원자료 읽기 승인으로 대체됐다.

읽은 원자료: `signal-history` 고정 커밋 `704d7db6d5b00def771aba5d2665d0846d6bc776`, replay 입력 manifest `f0781292f508a123c234ded6d28aa8e84a0dc3cc29500e14989dc0b68f53b4d2`. manifest 자체 canonical hash와 각 내용 주소 SHA-256을 검증했다. 미국 635 가격 패널, 2,266,906 가격 관측 및 782티커/34,945 원공시가 로드됐다(실제 점수에 쓰인 표본 수와 다르다). 공시는 고정 커밋의 Git blob과 SHA-256을 기록했다.

자체 프로토콜은 코드·helper·구성원·섹터·신원 메타데이터 해시를 고정한다. 기존 연구에서는 신원 감사 메타데이터만 재사용했고 과거 성과·예측·결과는 읽지 않았다. 봉인 원자료/manifest/연구 결과·예산·잠금·production 파일은 변경하지 않았다. 원격 잠금 생성 0, production 변경 없음.

방법 고정 커밋 `c124bf6`의 checkout(전체 Git 이력)과 requirements.txt/requirements-dev.txt 설치 환경에서 다음 명령으로 같은 고정 비교를 재현한다. Git 객체가 없으면 기존 GitHub 인증으로 해당 고정 입력 커밋을 fetch해야 한다. 새 데이터 수집이나 옛 연구 실행은 하지 않는다.

```bash
git fetch --no-tags --filter=blob:none origin 704d7db6d5b00def771aba5d2665d0846d6bc776
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python scripts/run_us_decision_pilot.py \
  --output-dir /workspace/us-decision-pilot-reproduction-v1 \
  --private-path-dir /workspace/us-decision-pilot-reproduction-private-v1
```

원실행 환경은 CPython 3.12.14, NumPy 2.3.1, pandas 2.3.0, exchange_calendars 4.11.1이었다. 집계 `result.json` SHA-256은 `4e5713dc3e7fa10ef6a83367ae47185a94005c46b9bd299d83f657f4bf65b8ed`다. CI의 Python 3.11 합성 검증과 실제 계산 환경을 구분한다.

출력 디렉터리는 없어야 한다. 원실행 출력은 `/workspace/us-decision-pilot-actual-v1`, 비공개 일간 전략 경로는 `/workspace/us-decision-pilot-private-paths-v1`에 있다. 공개 PR에는 집계 JSON·전략 지표·연도별 수익만 보존한다. 개별 주가·forward label·개별 보유 목록을 공개하지 않는다.

합성 테스트는 실제 성과 증거가 아니다. 실제 재현 실행은 고정 checkout의 해시를 엄격히 검사한다. CI의 해시 검증 단위 테스트는 합성 디렉터리를 사용하므로 이후 정상적인 AGENTS/워크플로 변경을 역사 해시로 막지 않는다. CI는 합성 테스트, 집계 산출물의 산술 일관성·표본 회계·해시 및 기존 repository 검사를 검증하며 실제 역사 연구를 재실행하지 않는다. 최종 SHA의 전체 검사 상태는 동일 Draft PR #245 Checks와 최종 인계에 기록한다.
