## 2. 추천 연구 방향과 이유

1. **목표를 "평균 순위"에서 "꼬리 확률과 선택 가치"로 바꾼다(Study A).** Bessembinder(2018, 2023)가 보인 수익 왜도 때문에 5종목 책의 성패는 상위 꼬리 적중과 좌측 꼬리 회피로 결정된다. 평가량은 `LOR(승자) − LOR(대형손실)`과 매칭 대조군 대비 초과수익 `Δ`이며, 같은 조건이 실패한 종목(대조군)을 분모에 반드시 포함한다.
2. **신호는 문헌에서 결과 열람 없이 3개만 고정한다.** 현금 확인 변곡점(A-H1), 변곡점의 가격 확인(A-H2), 산업 선도 후 후발(A-H3).
3. **조건부 국면은 시장 관측 변수와 진짜 거시 빈티지를 분리하고, 한국 경기 국면은 주장하지 않는다(Study B).** 상태별 비중첩 블록이 6개 미만이면 기술통계.
4. **노출 조절은 수익 개선이 아니라 손실 위험 수단으로 평가한다(Study C).** 절대수익·MDD/CVaR·참여·재진입 비용을 따로 보고한다.
5. **역사 결과는 개발 증거, 확증은 전향 기록뿐이다.** 2013~2026은 이미 노출됐다.

## 4. 최우선 실험 1개

**`rp1-c1-us-exposure-ladder-replication`** — 봉인된 KR 노출 규칙(PASSIVE, C0~C3)을 파라미터 변경 없이 S&P 500 1993~2026에 단 1회 적용해 KR 판정이 재현되는지 측정한다. 학습 모델 없음(결정론적 동결 규칙). 이유: 실제 보유물(ETF)에 바로 적용되고, 입력(DGS10·DGS3MO·VIXCLS)이 원래 미국 시계열이라 매핑 선택이 0개이며, 개별 종목이 없어 생존편향·종결 대가 문제가 없다. 상세는 문서 05 §3.

병행(결과 없음): H252·US H126 추론 보정(WP1), Study A 측정성·MDE 사전검사(WP5), KR 전향 기록 시작(WP6).

## 5. 중대한 위험

1. **6~12개월 지평의 검정력 부족.** 가정한 예시로 H252 독립 코호트 12개면 MDE ≈ 6.5%p/년. Study A 역사 검정이 아무것도 구별하지 못할 가능성이 높으며, A0가 이를 결과 열람 전에 측정한다.
2. **좌측 꼬리 절단.** 미국 퇴출 212개 무가격, KR 종결 22개 미해결. 승자·대형손실 분류는 생존편향에 가장 민감하다 → 두 독해 원칙.
3. **H252 미보정.** 보정 실패 시 사용자 목표 지평은 기술통계로만 남는다.
4. **미국 전향 차단.** 일간 가격 영속 수집 미승인, Finnhub 재무상태표 결측(2026-10-07~) → 미국에서는 확증 증거가 하루도 쌓이지 않는다. 소유자 결정이 필요하다.
5. **대형주 유니버스.** PEAD·산업 lead-lag·가치 등 문헌 효과는 소형·저커버리지에서 강했다. 이 저장소의 유니버스에서 약할 것이 사전 기대값이다.
6. **가격 기준이 검증되지 않았다.** 미국 종목·SPY 가격은 내부 재구성 총수익이고 외부 대조가 끝나지 않았다. #247의 `Fold`는 가격 기준이 `VERIFIED`가 아닌 라벨로 학습을 거부한다. 따라서 Study A 미국 역사 검정은 WP0(가격 기준 admission) 없이는 실행되지 않는다.
7. **노출층의 대가.** KR에서 C0는 낙폭을 12%p 줄이고 연 3%p를 잃었다. 미국에서도 같은 교환이면 이것은 위험 선호의 선택이지 알파가 아니다.
