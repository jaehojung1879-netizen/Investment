## 2. PIT 규칙

| 항목 | 규칙 |
|---|---|
| 가격 | 신호 = 신호일 종가, 체결 = **다음** 세션 종가. 같은 날 종가 체결 금지 |
| 미국 재무 | `max(availableFrom, acceptedDate)` **다음 날**부터 사용. 같은 회계기간·단계는 최초 공개본만. 보고기간말 180일 초과는 결측 |
| 한국 재무 | DART 접수일 **다음 날**. 정정 공시는 자기 접수일을 가진 별도 기록. 연결 우선, 연결·별도 혼합 TTM은 결측 |
| 주식수 | 이전 공시에서만 이월(뒤 공시 금지), `AS_FILED`/`CARRIED_FORWARD` 표기 |
| 구성종목 | 신호일보다 엄격히 이전 스냅샷 |
| 산업 | 날짜 있는 스냅샷/재구성 소속만, 현재 분류 소급 금지 |
| 시장 관측 금리·VIX | FRED 4 달력일 지연, 14일 초과 정체는 결측 |
| 거시 | ALFRED `realtime_start = realtime_end = T` 재구성값만. 빈티지 없는 열은 `PIT_UNSAFE`로 사용 금지 |
| 사건 플래그 | 사건 판정에 쓰인 모든 입력의 가용일 ≤ 신호일, 코드가 행마다 단언 |

## 3. 라벨·학습 누설 통제

- **만기 규칙:** `outcomeEndDate ≤ trainingCutoff`인 행만 학습. 미만기 행은 학습·보정 어디에도 들어가지 않는다.
- **외부 폴드:** 연 단위 확장창. 폴드 Y의 학습 라벨은 Y의 첫 앵커 신호일보다 **엄격히 이전에 종료**해야 한다.
- **내부 검증:** 블록 교차검증, 각 블록 첫 진입일 이후 종료 라벨 퍼지 + H세션 엠바고.
- **독 라벨 검사:** 컷오프 이후 종료 라벨을 모두 무작위 값으로 바꿔도 폴드 예측이 바이트 동일해야 한다(테스트 필수).
- **스파이 검사:** 사전 라벨 관문에서 멈춘 실행은 라벨·적합·예측 함수 호출 카운터가 0이어야 하며, 해당 함수를 예외를 던지는 스파이로 바꿔도 통과해야 한다(AGENTS v2.32, v2.40).
- **만기 최종성:** 라벨은 만기 세션이 최종 확정된 뒤에만 공개된다. KR은 최소 18:00 KST(`prospective_receipt_core.KR_CLOSE_FINAL_UTC`), US는 실제 XNYS 마감+60분(#246 `weekly-session-integrity-v1`, 조기 폐장·DST 반영). #247 `LabelReference`가 이를 검증하므로 직접 다시 구현하지 않는다.
- **정정 누설:** 최초 공개본만. 이후 정정된 숫자로 과거 사건을 판정하지 않는다.
- **발표 지연:** 미국 10-Q `acceptedDate`는 실적 발표일이 아니다. PEAD라고 부르지 않는다.

## 4. 데이터 자격 (Eligibility)

1. 신호일 적격성은 **신호일 정보만**으로 판정한다(유동성 하한, 우선주 제외, 신원 검증, 산업 분류 존재).
2. 순위·사건 판정은 적격 횡단면에서 먼저 확정하고, 그 다음에 결과 가용성을 본다. 결과가 없는 종목도 순위 슬롯을 차지한다.
3. 결과 보류 사유는 닫힌 어휘로 기록한다: `TERMINAL_CONSIDERATION_UNRESOLVED`, `DEPARTED_UNPRICED`, `NOT_MATURED`, `DIVIDEND_BASIS_UNRESOLVED`, `IDENTITY_UNVERIFIED`.
4. 종결 대가 미해결을 0원·마지막 종가·지수 수익으로 대체하지 않는다.
5. **두 독해 원칙(미국 생존편향):** 1차 통계량을 (a) 미해결 제외, (b) 미해결을 가설에 가장 불리한 그럴듯한 값으로 배정, 두 번 계산한다. (b)의 배정 규칙: S=1인 미해결은 `BIGLOSS`, 초과수익 = 같은 날짜 횡단면 5번째 백분위 / S=0인 미해결은 그 날짜 중앙값. 두 독해 부호가 같을 때만 주장한다.
6. 금융·부동산은 회계 사건 가설의 분모에서 `DEFINITIONALLY_EXCLUDED`로 분리 집계(0 채움 금지).

## 5. 통계 추론

| 항목 | 규칙 |
|---|---|
| 중첩 지평 | 수익률에 선형인 통계량만 1차. 달력주 귀속 후 `calendar_time_sn_interval`(엔진 `pipeline/alpha_inference_calibration_v4.py`) 적용. 튜닝 파라미터 없음 |
| 보정 | 해당 지역×지평의 포함확률이 합성 데이터에서 `PASS`된 경우만 1차 구간으로 사용(현재: KR H21/H126, US H63). 미보정 지평은 기술통계 |
| 순위 IC | Spearman IC는 기술통계. 1차 통계량이 될 수 없다(수익률에 비선형) |
| 다중성 | Study 1차 가설 가족 내 Holm α=0.05(최대 3개). 보조는 BY q=0.10. 평가 불가 슬롯은 p=1로 유지 |
| 모델 선택 | 2개 이상 설정 비교 시 DSR(시도 수 명시)·CSCV PBO 보고. 단일 설정이면 생략 |
| 무작위 대조 | 동일 층 내 플래그/점수 순열(사건 수·층 구조 유지), +1 보정 p값, 귀무가 속한 선택기 ID 표기 |
| 검정력 | 결과 열람 전 MDE 계산 필수. MDE > 사전 기대 효과면 역사 추론 실행 금지 |
| 경로 의존 지표 | MDD·CVaR·Sharpe는 비중첩 표본 또는 실제 NAV 경로에서만 |
| 판정 문구 | 구간이 0을 포함하면 `CONTAINS_ZERO`. 점추정이 불리한데 0 포함이면 "효과 없음"으로 순화하지 않는다 |

## 6. 벤치마크와 수익 분해

- **1차 벤치마크:** KR `069500.KS`(등록 총배당 정의), US `SPY`(내부 재구성 총수익, 외부 대조 미완료 명시). 대체 지수·ETF 혼용 금지.
- **분해 사다리(미국 파일럿 교훈):** 같은 기간에 다음 네 수준을 반드시 따로 보고한다.
  1. 벤치마크 → 적격 유니버스 동일가중 바스켓(가중 방식·유니버스 효과)
  2. 유니버스 동일가중 → 같은 업종 비중의 동일가중(업종 배분)
  3. 업종 맞춤 바스켓 → 선택 종목(업종 내 선택)
  4. 총수익 → 순수익(비용)
  #245에서 SPY 대비 −3.45 로그pp의 가장 큰 항이 동일가중 전환(−5.92)이었고 선택은 +4.12였다. 분해 없이 "벤치마크 미달"만 보고하면 선택 실패로 오독한다.
- **기하 vs 산술:** CAGR 차이는 산술 선택 + 복리 항으로 분리(`selection_value.decompose_edge`).
- 로그pp와 CAGR pp를 더하지 않는다.

## 7. 비용과 포트폴리오 제약

- 비용: `benchmark_alpha.REALISTIC_COSTS`(한국 연도별 증권거래세 포함). 1×, 2×, 3× 스트레스. 지수 ETF는 별도 비용(국내 주식형 ETF 거래세 0).
- 회전율: **교체된 종목**과 **비중 재조정**을 분리 보고.
- 제약: 최대 5종목, 섹터당 2종목, 0종목 허용, 잔여는 지역 지수 ETF(현금 목표 없음 — 수동보유 우선). 레버리지·공매도 없음. 종목당 상한 15%(`config.json longterm.maxNameWeight`).
- 종목 편입의 경제적 관문: 보정된 기대 순초과수익 > 왕복 비용(종목 + ETF 매도). 보정 값이 없으면 활성 비중 0.

## 10. 실행·봉인 절차 (기존 패턴 재사용)

- 사양 파일은 `docs/research-program/specs/`에 둔다. **`research_specs/`와 `docs/results/`에 새 파일 추가 금지** — Phase C 등록이 폴더 전체를 보호 해시로 고정한다(`weekly-passive-first-v1.md`).
- 결과는 `docs/research-program/results/`에 정확 바이트로 봉인.
- 실행 전 관문: 사양 해시, 입력 스냅샷 해시, 코드 해시, 결과·잠금 부재 확인 → 잠금 ref 원자적 생성 → 그 후에만 결과 열람(카운터로 증명).
- 워크플로는 `workflow_dispatch` 전용, `main`에서만, 사람 승인 파일(사양·코드 해시 고정) 필요.
- 결과 판정(PASS/FAIL/INCONCLUSIVE/NO_EVIDENCE)은 프로세스 성공(exit 0). 인프라 오류만 비정상 종료.
- 봉인 스크립트는 실제 하위 프로세스로 실행하는 테스트를 가진다(`__main__` 누락 무동작 사고 재발 방지, AGENTS v2.48).
