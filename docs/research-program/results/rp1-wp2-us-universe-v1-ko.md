# WP2 · 미국 모집단 신원·커버리지 고정

**판정: R-b. Study A-US A0의 모집단 관문 진입 가능. A0 통과·A1 실행 승인은 아님.**

2013~2025년 XNYS 모든 거래일의 직전 엄격 이전 S&P 500 관측 스냅샷을 사용했다. 총 **1,644,238 구성원-일**이다. 기존 census와 비교할 수 있도록 완료 주간 그리드도 별도로 측정했고 같은 R-b 판정이다. 원천·사양·코드·공통 표본·전체 적격/보류 마스크 해시는 [기계 판독 측정본](rp1-wp2-us-universe-v1.json)에 있다.

## 분모와 고정 규칙

- 분모는 금융·부동산·신원·가격 제외 **이전**의 전체 당시 구성원-일이다. 비금융 분모 비율도 JSON에 함께 남겼다. 연도마다 정수식 `2 × 적격 수 ≥ 전체 수`를 적용하며, 하나라도 미달이면 실패한다. 둘 다 통과하면 R-a 우선이라는 WP2 기준을 변경하지 않았다.
- R-a는 #245의 신원 연결과 당시 스냅샷 CIK ↔ 이미 공개된 공시 CIK 일치를 요구한다. 이번 수는 신원·가격 가용성 수이며, #245의 회계 완전 사례·253일 특징 창까지 통과한 수가 아니다. 회계 측정성은 WP5에서 분리한다.
- R-b는 replay-v16의 정확한 과거 심볼 ↔ 가격 패널 연결이며 CIK를 과거로 소급하지 않는다. 신규 별칭 접합은 없다. `PROVISIONAL` 신원이며 `VERIFIED_SECURITY`가 아니다.
- 두 후보에 공통으로, 결과 열람 전에 문서화된 신원 충돌(v3 패널이 구성 기간 뒤에 시작/티커 재사용/미해결 식별자, #245 PARA)을 보류했다. 원래 replay-v16을 수정한 것이 아니라 Study A의 공통 admission이다. 보류 이름도 전체 분모·표본 ID·보류 마스크에 남긴다. JSON의 `legacyRawJoinMemberDays`는 이 관문 전 원래 연결 수다.
- 가격은 **동일 세션 양의 유한 종가 존재 여부**만 즉시 투영했다. 유동성·연속 가격 이력·기업행동 수익 기준 또는 종결 대가가 검증됐다는 뜻이 아니다. CIK 일치도 가격 공급자의 증권 ID를 보증하지 않는다.

## 남은 신원·생존편향

- 마지막 보존 스냅샷(2026-09-05)에 없는 과거 **raw 심볼 326개**, 직접 패널 전무 **196개**, 직접 패널로 신원을 안전하게 주장할 수 없는 심볼 **227개**다. 이 227은 개명·비정상 원식별자도 포함하는 raw 심볼 진단이라 기존 정규화된 212개 감사 수와 같은 분모가 아니다. 지수 퇴출을 상장폐지로 해석하거나 종결 대가를 0/마지막 가격으로 채우지 않는다.
- 퇴출 이름의 무가격 구성원-일은 전체 분모의 2013년 **31.90%**에서 2025년 **2.78%**로 치우친다. 퇴출 구성원-일만 분모로 하면 각각 **75.01% / 45.82%**다. 과거 표본의 생존 조건부 한계는 그대로다.
- 의심 패널 **46개**의 심볼·원인·패널/구성원 날짜·연도별 노출 수만 JSON에 실었다. 가격 변화율은 측정하지 않았다. **PARA는 가격 존재 656 구성원-일이 전부 있어도 신원 미검증으로 보류**한다. 공급자 증권 ID 확인 없이 어느 다른 발행사인지 단정하지 않는다.
- ABC→COR, CDAY→DAY 등은 기존 증거로 진단할 뿐 새 접합·신원 복구를 하지 않았다. CIK가 같은 동시 상장 주식 종류는 합치지 않는다.
- 스냅샷 경과 최대 **767일**, 같은 날 여러 원천 관측은 **3일**이다. 기존 `MembershipSnapshots`의 안정 정렬·엄격 이전 선택을 유지했다. 실제 편입·편출 시행일, 스냅샷 사이 구성 변화, 완전한 GICS taxonomy 버전은 미해결이다.

## WP5에 넘길 최소 조건

1. 이 사양·원천 커밋·전체 표본 및 적격/보류 마스크를 그대로 소비한다. R-b 신원을 `PROVISIONAL`로 표시하고 보류 이름을 분모에서 지우지 않는다.
2. #247 `filing_prefix`와 #250/#253 특징·계층 계약으로 A-H1~H3의 당시 가용성을 측정하고, 결과 전 고정한 산업 매핑을 사용한다. 사건 유병률 3~50%, 측정성 60%, 날짜당 US 10개, 구별성 |ρ|≤0.70 관문을 별도로 적용한다.
3. WP1의 합성 보정·선택 지평 및 실제 표본 구조에 따른 MDE(연 4%p 이하)를 확인한다. 이 PR은 WP1 파일을 수정하거나 그 결과를 대신하지 않는다.
4. WP5는 결과 없는 A0까지만 가능하다. A1에는 추가로 WP0 수익 기준 admission과 별도 명시적 소유자 승인이 필요하며 기존 경제적 차단을 해제하지 않는다.

## 재현과 검증

기존 #247의 로컬 Git 허용 목록을 상속하고 고정 신원 증거 blob 하나만 추가했다. 새 수집·외부 원천·라이선스 허가·Secret·설정·워크플로는 없다. 기존 자료의 원천 lineage는 210개 blob/내용 해시 영수증으로 남겼으며 신규 재배포 권한을 주장하지 않는다. 기본 실행은 `PREVIEW_ONLY`다.

```bash
python scripts/rp1_inspect_us_universe.py
python scripts/rp1_inspect_us_universe.py --inspect > /tmp/rp1-wp2-repeat.json
python -m pytest -q tests/test_rp1_us_universe.py
```

실제 보존 입력을 두 번 독립 로드해 **49.80초 / 48.92초**, 완전 동일한 JSON 바이트를 얻었다. 결과·라벨·포트폴리오·학습 진입점 11개를 예외 스파이로 교체한 실제 두 측정에서 호출 수는 모두 0이다. 결과 접근·학습·잠금 카운터도 0이다. 개별 가격·수익률·승자 라벨은 출력하지 않는다.
