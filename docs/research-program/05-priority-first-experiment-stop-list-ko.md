## 3. 최우선 실험: `rp1-c1-us-exposure-ladder-replication`

### 3.1 한 문장

**봉인된 `kr-market-risk-model-v1`의 노출 규칙(PASSIVE, C0, C1, C2, C3)을 파라미터 하나 바꾸지 않고 미국 S&P 500에 1993~2026년 적용해, KR의 판정(`NO_CANDIDATE_NOMINATED_CONTROL_RETAINED`, 낙폭 감소와 수익 손실의 교환)이 다른 시장에서 재현되는지 단 1회 측정한다.**

### 3.2 왜 이것이 먼저인가

1. **실제 결정에 바로 닿는다.** 지금 시스템은 한국 709/713주, 미국 전 기간 지수 100%를 보유한다. 종목 알파는 두 지역 모두 입증되지 않았다(KR Phase C 지명 0, 미국 #245 NOT BEATEN). 따라서 다음 6~12개월 동안 실제 손익을 바꿀 수 있는 유일한 층은 "ETF를 얼마나 보유할지"다.
2. **재사용률이 가장 높다.** KR 규칙의 입력 중 SLOW(DGS10−DGS3MO)와 TRANSITION(VIXCLS)은 **원래 미국 시계열**이고, FAST는 지수 종가만 쓴다. 지역 매핑 선택이 하나도 없다. 상태기계·결정 규칙·지표 함수가 `pipeline/kr_market_risk_model.py`에 봉인돼 있다.
3. **무결성 위험이 가장 낮다.** 개별 종목이 없으므로 퇴출 종목·종결 대가·재무 PIT 문제가 없다. 파라미터 선택 0개라 과최적화 자유도가 없다.
4. **독립성이 일부 있다.** 규칙은 KR 데이터(해부 v2는 1990~2026 KR 지수를 기술적으로 봤고, 모델 평가창은 2007~2026)에서 설계됐다. 이 저장소는 미국 지수에 이 규칙을 적용해 본 적이 없고, 특히 미국 1993~2006(닷컴 붕괴 포함)은 어떤 시장위험 연구도 측정하지 않았다. 단 미국 지수 역사는 공개적으로 잘 알려져 있고 연구자 일반 지식에 노출돼 있으므로 등급은 `FROZEN_RULE_REPLICATION`이지 확증이 아니다.
5. **어느 결과든 다음 행동이 정해진다**(문서 03 §C.7 해석표). 결과가 불리해도 "노출층 탐색 종료"라는 비용 절감 결론이 나온다.

### 3.3 모델 추천

**학습 모델 없음.** 결정론적 동결 규칙 4개 + 수동 기준. 이유: 미국 1993~2026의 낙폭 15% 이상 에피소드는 10회 안팎이고, 그 수로는 어떤 추정 모형(HMM, 로지스틱 위기 분류, 변동성 목표의 목표값 추정)도 파라미터 수보다 독립 사건이 적다. Cederburg 외(2020)가 보인 변동성 관리의 구조적 불안정도 같은 이유다. 복잡한 추정 모형과의 비교는 이 복제가 끝난 뒤 별도 사전등록으로만(그리고 C.7 결론이 "노출층 탐색 종료"면 하지 않는다).

### 3.4 사전 고정 사양 (구현 PR이 기계 판독 사양으로 봉인)

| 항목 | 값 |
|---|---|
| 1차 기준 자산 | S&P 500 가격지수(^GSPC 일간 종가), **KR과 동일하게 가격지수·현금 0%** |
| 사전 고정 경제적 독해 | SPY 수정종가 총수익 + DTB3 현금(1993-01-29 SPY 상장 이후) |
| 입력 | ^GSPC, FRED `DGS10`, `DGS3MO`, `VIXCLS`, `DTB3` — 단일 공급자 경로, 이어붙이기 금지 |
| 달력 | XNYS 세션(KR의 XKRX 자리에 대입). 주말 판단·다음 세션 종가 체결 |
| 층 정의 | FAST: 종가 < 200일 평균 + 연율 vol63 > 25% · SLOW: 10y−3m > 0이고 직전 504세션 내 < 0 · TRANSITION: VIX 과거전용 확장 백분위 ≥ 0.80(≥156 주간 관측) — **전부 KR 상수 임포트** |
| 후보 | PASSIVE(1.0 고정), C0, C1, C2, C3, 배수 {1.0, 0.7, 0.4} |
| 결측 | 결측 층의 모든 완성에서 배수가 같을 때만 결정, 아니면 직전 목표 유지(KR 규칙) |
| 비용 | 매수 8bp·매도 8.3bp(미국 `REALISTIC_COSTS`), 1×/2×/3× |
| 창 | 첫 결정일: VIX 156주·FAST 200세션·SLOW 504세션이 모두 정의되는 첫 주말(1993년 초 예상, WP4에서 데이터로 확정) ~ 입력 스냅샷 마감 |
| 하위구간(기술통계) | 첫 결정일~2006-12-31 / 2007-01-01~마감(KR 창과 겹치는 구간) |
| 판정 | 문서 03 §C.6 규칙 그대로(KR 사양에서 값 임포트, 재기술 금지) |
| 보고 | 문서 03 §C.5 지표 전부, 후보별 1×와 총수익 |
| 실행 | 일회성 잠금 ref, `workflow_dispatch`, 사람 승인 파일 |

### 3.5 사전 고정 중단·해석 기준

- 데이터 품질 관문 실패(XNYS 세션 대비 결측 > 0.5%, 비달력 날짜 존재, 공급자 경로 둘 이상) → 실행하지 않고 `DATA_INSUFFICIENT`. 관문 기준을 낮춰 재시도하지 않는다.
- **KR 봉인 결과 재현 검사 실패** → 실행 금지. 일반화된 래퍼에 KR 입력을 넣었을 때 `docs/results/kr-market-risk-model-v1-result.json`의 결정 블록·축 값이 1e-12 이내로 같아야 한다(문서 06 WP4).
- 결과 해석은 문서 03 §C.7 표만 사용. 표에 없는 결과는 `UNANTICIPATED_PATTERN_NO_ACTION`으로 기록하고 어떤 승격도 하지 않는다.
