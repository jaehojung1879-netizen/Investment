# Winner & Inflection Discovery — Exploratory Program

독립적인 승자·실패 기업의 **상승 이전 상태 변화** 탐색 기반이다. Claude의 시장위험·ETF 노출 연구와 선후행 관계가 없다. main `0131a0d`에 병합된 #247을 재사용했고, 미병합 Draft #248의 Study A는 참고했다. 이 PR은 실제 미래 수익률·승자 라벨을 열거나 역사 모델을 학습하지 않는다. KR Phase C 및 다른 봉인의 명세·결과·잠금, 운영 정책은 수정하지 않았다.

검토할 실행 계획은 [protocol-v1.json](protocol-v1.json), 입력 실측 원본은 [readiness.json](readiness.json)이다. 프로토콜의 `PREVIEW_REVIEW_REQUIRED`는 실행 승인이 아니다. 기존 KR 연구와 저장소의 공개 결과를 이미 접한 환경이므로, 나중의 역사 탐색도 독립 OOS 증거로 주장하지 않는다.

## 패턴 정의와 우선 세 실험

`pipeline/winner_inflection.py`는 원천 공개 시점까지의 prefix에서만 TTM을 만든다. 분기 누적 흐름을 네 번 더하지 않고 기존 DART/Finnhub rollforward를 그대로 호출한다. 직전 상태는 반드시 직전 회계 분기다. 재무상태표를 과거 값으로 대체하지 않는다. 두 시장 모두 보고 기간 말부터 180일이 지나면 이번 탐색의 재무 특징을 보류한다.

| 패턴 | 측정할 상태 변화와 시점 | 구현/가용성 판단 |
|---|---|---|
| A 성장 가속 | `g_t = TTM_t / TTM_(동기전년) - 1`; 매출·영업이익 각각 `g_t - g_(직전분기)` | 구현. 두 전년 분모가 양수여야 한다. 음수 영업이익의 전환은 B로 측정하며 무한 성장률로 바꾸지 않는다. |
| B 현금흐름·수익성 변곡 | 영업이익/매출 및 OCF/매출의 직전분기 TTM 대비 변화, 각 흐름의 `이전<=0<현재` 사건 | 구현. 비교 매출은 양수, 0은 관측된 거짓 사건일 때만 사용한다. 자산 분모가 없어 BS 결손과 분리할 수 있다. |
| C 산업 상대강도 개선 | 연속된 과거 63거래일 두 구간에서 `(자기 수익−같은 날 산업 동료 중앙값)`의 변화 | 구현. 각 구간은 127개 정확한 완료 거래일 가격에 연결한다. 자기는 제외하고 같은 당시 유니버스의 측정 가능한 동료 최소 5개를 요구한다. US 세부 업종/오타를 임의로 상위 섹터로 바꾸지 않는다. |

첫 실제 평가 후보는 **A, B, C를 각각 분리한 실험**이다. A는 현재 성장률 수준 대비 가속이 주는 추가 정보, B는 현재 이익률 수준 대비 전환 사건·현금 확인의 추가 정보, C는 기존 모멘텀 대비 산업 내 변화가 주는 추가 정보를 비교한다. C 단독의 개선을 새로운 기업 변곡점 발견으로 부르지 않는다. 그다음 A/B×C의 사건 순서·상호작용을 별도 버전으로 탐색할 수 있다. 기존 팩터의 가중합 점수표를 추가하지 않았다.

아래 D~G 수치는 필요한 입력 일부가 만나는 **상한**이다. 해당 패턴의 완성 특징 행은 아직 만들지 않았으므로 가용률로 승격하지 않는다. 원천 결손에 따른 상한 밖 표본과 `PATTERN_IMPLEMENTATION_PENDING`을 구분한다.

| 패턴 의존 입력 상한 | KR / 85,680 member-dates | US / 359,526 member-dates |
|---|---:|---:|
| D: B와 C | 18,561 (21.663%) | 181,092 (50.370%) |
| E: C | 59,550 (69.503%) | 294,395 (81.884%) |
| F: A와 B | 24,124 (28.156%) | 164,707 (45.812%) |
| G: OCF margin 변화와 정확한 과거 가격 | 28,828 (33.646%) | 244,665 (68.052%) |

새 실측의 연도·산업별 분모/가용률, A/B 원인 코드 조합, C 가격/산업/동료 결손은 readiness JSON에 있다. KR C는 미확인 기업행동 13, 설명되지 않은 가격 변화 213, 공식 거래 창 미충족 5,574 member-date를 보류했다. US C의 정확한 거래 가격 창 결손은 60,854 member-date다. KR의 작은 산업 표본은 동료 최소 수 때문에 C가 전혀 측정되지 않을 수도 있다(AUTOS 0/2,727); 산업 간 결측이 무작위라고 가정하지 않는다.

US의 영업이익은 기존 빌더의 은행·보험 세전이익 fallback을 이 연구에서는 사용하지 않는다(`OPERATING_SUBTOTAL_NOT_STATED`). 금융/부동산은 별도 경제적 층으로 다루고, 주 분석의 제외 매핑은 날짜 있는 분류로 확정해야 한다. KR는 원천 의존 레코드들의 CFS/OFS가 다른 경우 이번 특징 묶음을 보수적으로 함께 보류한다. 실제 공개일 이전의 정정치를 소급하지 않는다. US의 원천 period-slot 선택은 기존 earliest-visible 규칙, KR는 기존 visible-prefix 인덱스 규칙이다.

## 실제 결함과 연구에 미치는 영향

* KR: 당시 유니버스에 등장한 260개 증권 중 정확한 DART 연결은 254개, 6개(2.308%)는 미해결이다. 신원 연결은 사후 issuer bridge이며 당시 증권 신원 증명이 아니다. 종결 대가 미해결 22개/260개(8.462%)는 별도 분모이고 6개와 단순 합산하지 않는다. 공시 2건의 접수일 불일치는 기존 어댑터가 제외한다. 산업은 v4의 부분 복원 상태를 유지한다.
* US: 당시 심볼 829개 중 신원 분류표는 827개만 대응한다. 잘못된 `American Airlines Group`, `RVTY (Previously PKI)`를 자동 정정하지 않았다. 분류표 827개 중 `DEPARTED_NO_PANEL_REASON_UNRESOLVED` 181개(21.886%), 다른 issuer의 ticker 재사용 29개(3.507%), rename 14개(1.693%)와 별도 acquired/merged 1개(0.121%)가 있다. CIK 결손 42개(5.079%)와 주식 종류 영구 ID 미검증도 남아 있다. 이들은 겹칠 수 있으며 현재 생존 기업으로 치환하지 않는다. rename successor 13개는 자동 적용하지 않는다.
* S&P 구성원은 당시 날짜 있는 커뮤니티 스냅샷이고 공식 S&P 원본·발표 시각 증명은 아니다. #247의 세부/비일관 산업 라벨 3,777 member-date는 자동 crosswalk하지 않는다. 새 C 실측은 허용된 coarse 라벨과 동료 분모를 추가 확인하므로 #247의 단순 산업 라벨 존재율과 다르다.
* DART 원천 공개일은 2015-04-29~2026-09-16, 수집 관측 시각은 2026-09-27~28이다. Finnhub 공개일은 2012-01-31~2026-10-13, 수집은 2026-09-13~10-15이다. 과거 공개 정보의 재구성이며 과거에 이 저장소가 실제로 관측한 전향 기록이 아니다. US acceptedDate 1건 결손은 원천 분모에 남긴다. 공개일 당일에는 쓰지 않는다.
* US 2026-10-07~10-10 수집 618건의 BS 전체 결손, 10-11·10-15 각 1건을 포함한 최근 620건은 자산/부채/자본 기반 분석을 막는다. 이전 BS를 현재 BS로 대체하지 않는다. A/B의 흐름·매출 분모는 재측정해 유지 가능한 후보를 분리했다. BS 없이 레버리지·ROA·발생액/자산·순자산 가치 순서를 검증할 수는 없다.
* replay-v16의 Close는 원시 거래가와 동일하지 않은 내부 수익 기준이다. C의 과거 경로는 KR 기존 `TickerBars.basis_cause`와 공식 거래 마스크를 함께 사용한다. US 배당/분할 전체 검증과 양 시장 종결 대가 검증은 미래 shareholder-return 라벨 승인 전에 별도로 필요하다. 미래 보유 주식의 가격 결손을 마지막 가격 매도로 처리하지 않는다.

원천 재무 결손을 0으로 채우면 공시 부재가 적자·전환·낮은 위험으로 바뀌고, 상폐 결손을 0 수익으로 채우면 실패 집단이 좋아진다. 입력 검사에는 대체가 없다. 합성 모델에만 train-only median+missing indicator를 검증했고, 학습 열 전체가 결손이면 해당 열을 제거한다. 데이터가 충분한 패턴을 결손 패턴과 함께 일괄 폐기하지 않는다.

## 최소 실험 코드와 비교 방법

재사용 자산은 #247의 `Observation/Key/Source/Cell`, 별도 `LabelReference`, `Fold`, 경제성·preview 계약, 원천 `Sources` 검사기다. DART/Finnhub TTM·단위 판정, US 공개일/current period 선택, KR 거래·기업행동 guard, PIT 구성원·산업 조회도 기존 구현을 호출한다. 비용·최대 5개 선택·회전율 계산은 실제 실행 구현 시 기존 `benchmark_alpha`, `weekly_decision`, `kelly_portfolio`를 사용하도록 명세했다. 새 거래비용 엔진이나 운영 selector는 만들지 않았다.

`winner_inflection_exploration.py`의 `training_plan`은 전체 `Observation` 분모를 먼저 검증한 뒤 별도 라벨 **메타데이터만** 연결한다. 신원/거래 불가·중복·만기 미도달·종결 대가 미확정·중첩 구간을 이유 코드로 남긴다. 평가일 예측에는 미래 라벨의 존재를 요구하지 않는다. `RunLayout`은 universe/features/labels/decisions/evaluation의 절대 경로가 서로 포함되거나 겹치지 않게 검증한다. 실제 테이블 emitter와 역사 라벨 reader는 미구현이다.

`compare_synthetic`는 `SYNTHETIC:` 증권과 `synthetic:` 원천·라벨만 허용한다. 단일 사건 규칙, L2 logistic의 승자/큰 손실 분류, Ridge/Elastic Net 조건부 수익 예측을 같은 fold에서 연습한다. seed=19, 기본 정규화 강도를 명시했고 sweep은 없다. 얕은 부스팅은 충분한 표본 및 별도 명세가 생길 때의 인터페이스만 남겼다. 합성 확률도 미보정 상태이며 투자 신호가 아니다.

향후 공통 라벨은 다음 거래일 종가 진입 후 H126/H252의 **동일 기준 shareholder 총수익률−시장 ETF 총수익률**이다. 같은 예측일·적격 집단의 top/bottom decile 및 양/음 초과수익으로 승자/큰 손실을 구분한다. 표본 30개 미만과 미해결 결과는 BLOCKED이고 중립이 아니다. 12~24개월 추세·경로와 실적 개선 자체의 결과 라벨은 H252/H504 등 별도 정의/구현 승인 이후에 연다.

탐색 모델은 모든 패턴에 같은 날짜·시장·H·신원/거래 자격·비용·대조군을 적용한다. 원천 결손률과 complete-case 표본 탈락률을 함께 보고한다. 현재 성장/이익률 및 기존 모멘텀·산업·규모 통제와의 비교를 추가 정보 판정 기준으로 삼는다. 상위 5개 경제성 평가 전에는 예측·확률 보정·검증된 라벨이 필요하다. 실제 선택은 합산 최대 5개이며 KRW/USD를 환율 정의 없이 합산하지 않는다.

중복 정보 진단은 (1) pairwise 표본 수를 붙인 Spearman, (2) 결측 마스크 Jaccard, (3) 사건 co-occurrence, (4) train에서만 맞춘 잔차, (5) 동일 표본의 한 패턴 제거 비교다. 특징 상관이 낮다는 사실을 독립 알파로 부르지 않는다. 확률은 base rate·PR-AUC·log loss·Brier·보정도, 연속 예측은 오차·rank correlation, 실패는 큰 손실 누락과 상승 전 닮은 실패 기업을 함께 본다. 수익성은 gross/net, 이름 교체/비중 재조정 회전율, 비용·시장 ETF·현금을 나누어 본다. 아직 어느 지표도 실제 역사 자료로 계산하지 않았다.
