서비스 이용방법

한국거래소 OPEN API 서비스의 이용방법을 안내하여 드립니다.
  1. STEP 01 로그인/인증키 신청
    • - Data Marketplace 회원가입 후 로그인
      (법인 : 사업자 정보 등록 /
      개인 : 본인인증 또는 소셜 로그인)
    • - 인증키 신청
      (관리자 승인 후 사용 가능)
  2. STEP 02 API 서비스 목록 검색
    • - 서비스 목록과 명세서를 통해 원하는
      API 서비스를 탐색
    • - 샘플기능을 사용하여 API 데이터 호출 테스트
  3. STEP 03 API 활용 신청
    • - 원하는 API 서비스 활용신청 후
      관리자 승인대기
  4. STEP 04 개발 적용 및 서비스 개시
    • - 관리자 승인 후 API 서비스를 이용하여
      대외 서비스 개시
