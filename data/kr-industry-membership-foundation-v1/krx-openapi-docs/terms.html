국문

제1장 총 칙
제1조(목적)

본 약관은 한국거래소가 제공하는 OPEN API 서비스를 이용함에 있어 이용에 관한 제반 사항과 기타 필요한 사항을 규정함을 목적으로 한다.

제2조(용어의 정의)

본 약관에서 사용하는 주요 용어의 정의는 다음과 같다. 정의되지 않은 것은 관련 법령이나 기타 일반관례에 따른다.

  1. ① "API"란 Application Programming Interface의 약자로, 정보 소유자가 정보 이용자에게 정보를 제공하기 위하여 정의한 규약을 말한다.
  2. ② "API 서비스"란 KRX Data Marketplace(한국거래소의 시장정보 포털을 말한다)상의 정보를 제공받은 이용자가 동 정보를 활용하여 직접 응용프로그램과 서비스를 개발할 수 있도록 한국거래소에서 제공하는 서비스를 말한다.
  3. ③ "인증키"란 API 이용자가 API 서비스 이용허가를 받은 개인 또는 법인임을 식별할 수 있도록 한국거래소가 API 이용자에게 개별적으로 부여하는 고유한 값을 말한다.
  4. ④ "API 이용자"란 한국거래소가 제공하는 OPEN API서비스를 이용하는 모든 개인 또는 법인으로서, 이 약관에 동의한 자를 말한다.
제3조(약관의 효력발생 및 변경)
  1. ① 본 약관은 API 서비스의 이용을 위하여 본 약관에 동의를 함으로써 효력이 발생한다.
  2. ② API 서비스의 모든 서비스는 본 약관에 동의한 경우에 한하여 제공한다.
  3. ③ API 서비스를 이용하기 위해서는 본 약관에 동의한 후 인증키 발급을 신청하여야 한다.
  4. ④ 한국거래소는 필요한 경우 본 약관을 개정할 수 있으며, 개정시에는 그 개정의 주요내용 및 적용일자를 홈페이지에 게시한다. 다만, 약관의 개정에 따라 이용자의 이용 조건 등이 제한되는 경우에는 적용일자로부터 15일 전까지 공지하고 이용자에게 이메일 등의 수단으로 개별적으로 통지한다.
  5. ⑤ 약관의 변경 사실 및 내역을 확인하지 않아 발생한 모든 손해에 대한 책임은 API 이용자에게 귀속된다.
제4조(약관에 명시되지 않은 사항)

본 약관에 명시되지 않은 사항은 관계 법령과 한국거래소 업무규정 등에서 정하는 바에 따른다.

제2장 이용 방법, 조건 및 절차
제5조(제공방법)
  1. ① API 서비스 이용을 희망하는 자는 한국거래소에 API 서비스 인증키를 신청하여야 한다.
  2. ② 한국거래소는 약관 동의 등 일정 요건을 갖춘 API 서비스 신청자에게 인증키를 부여하며, 이용자는 선량한 관리자의 주의의무를 다하여 인증키를 관리하여야 한다.
  3. ③ API 서비스의 이용기간은 제공기관이 인증키를 제공한 날부터 1년으로 하며, 이용기간 만료 전에 이용자의 연장요청이 있는 경우 1년 단위로 연장할 수 있다.
  4. ④ 한국거래소는 다음 각 호의 어느 하나에 해당하는 사유가 있는 경우 제1항 또는 제3항에 따른 인증키 신청 또는 연장요청을 거부할 수 있다. 이 경우 그 사유를 해당 이용자에게 통지하여야 한다.
    1. 1. 이 약관에서 정한 사항을 위반한 이용자의 신청인 경우
    2. 2. 그 밖에 한국거래소가 이용자의 신청이 부적절하다고 판단하는 경우
  5. ⑤ API 서비스의 이용시간은 한국거래소의 업무상 또는 기술상 특별한 지장이 없는 한 연중무휴, 1일 24시간을 원칙으로 한다. 다만 다음 각 호의 경우는 예외로 하며, 사전에 홈페이지를 통하여 관련 내용을 공지한다.
    1. 1. 시스템 정기 점검 등을 위하여 한국거래소가 별도로 정한 시간 또는 기간이 있는 경우
    2. 2. 일부 서비스에 대하여 한국거래소가 별도로 정한 이용시간이 있는 경우
제6조(서비스 이용 시 주의사항)
  1. ① API 이용자는 API 서비스를 이용한 결과를 구성함에 있어 다음 각 호에 해당하는 내용과 결합하여 구성할 수 없다.
    1. 1. 공공질서 및 미풍양속에 반하는 경우
    2. 2. 범죄행위에 관련되는 경우
    3. 3. 국익 또는 사회적 공익을 저해하는 경우
    4. 4. 타인의 명예를 훼손하거나, 타인에게 불이익을 주는 경우
    5. 5. API 서비스를 손상시키는 등 서비스의 건전한 이용을 저해한 경우
  2. ② API 이용자는 API 서비스를 비상업적인 목적으로만 이용할 수 있으며, API 서비스를 이용한 결과에 대한 대가를 제3자에게 청구해서는 아니된다.
  3. ③ API 이용자는 API 서비스를 이용한 결과의 앞, 뒤, 중간 등에 다른 내용을 삽입하거나 왜곡할 수 없고, 타인으로 하여금 결과의 내용 및 의도 등을 오인하게 해서는 아니된다. 또한 URL 등 API 서비스로 제공되는 모든 내용을 API이용자가 임의로 변조해서는 아니된다.
  4. ④ 한국거래소에서 제공하는 API 서비스의 결과를 API 이용자가 왜곡한 경우 한국거래소는 API 이용자에게 민사․형사적 필요한 조치를 취할 수 있다.
제7조(금지사항)

이용자는 다음 각 호의 행위를 하지 않아야 한다.

  1. ① 속임에 의한 이용자 사칭
  2. ② 바이러스ㆍ웜 등 악성코드의 전파
  3. ③ 저작권 위반이나 『정보통신망 이용촉진 및 정보보호 등에 관한 법률』의 불법정보 등과 결합 또는 연계 이용
  4. ④ API 연결방식의 위ㆍ변조
  5. ⑤ API 인증키의 양도, 증여 및 담보 목적물 사용
  6. ⑥ 접근이 허용된 범위가 아님에도 권한 없이 접근을 시도하는 행위
제8조(제공중단)
  1. ① 한국거래소는 API 서비스의 범위를 제한하거나 별도의 이용 가능 시간 또는 이용가능 횟수를 지정할 수 있다.
  2. ② 한국거래소는 다음 각 호의 어느 하나에 해당하는 경우 API 서비스 제공을 일시적으로 중단할 수 있다. 다만 부득이한 경우에는 예고 없이 서비스를 중단할 수 있다.
    1. 1. 관련 법률 개정으로 인해 API 서비스 제공 대상이 변경되어 더 이상 활용을 할 수 없을 경우
    2. 2. 시스템 정기점검, 증설 및 교체의 경우
    3. 3. API 서비스 제공에 있어서의 기술적 결함이 발견되는 경우
    4. 4. 신규 API 서비스를 추가하는 경우
  3. ③ 제7조의 금지사항이 발생하거나 이용자가 본 약관의 내용을 위반하는 경우 한국거래소는 API 서비스 제공을 중단할 수 있으며, 법적 조치를 포함하여 필요한 조치를 취할 수 있다.
  4. ④ 하나의 키당 1일(매일 0시~24시) 10,000회 이하의 요청으로 제한하며, 이를 초과할 경우 서비스가 중지될 수 있다.
  5. ⑤ 한국거래소에서 발급된 인증키는 12개월간 미사용시 사전 공지 없이 삭제될 수 있다.
제9조(API 이용자의 의무)
  1. ① API 이용자는 API서비스를 이용함에 있어서 본 약관에서 규정하는 사항과 기타 한국거래소가 정한 제반 규정, 공지사항 및 관계 법령을 준수하여야 한다.
  2. ② API 이용자는 한국거래소의 업무에 방해가 되는 행위 또는 한국거래소의 명예를 훼손하는 행위를 해서는 아니된다.
  3. ③ API 서비스를 이용함에 있어서 API 이용자의 행위에 대한 모든 책임은 당사자가 부담하고, API 이용자는 어떠한 경우에도 한국거래소를 대리하지 않으며, 한국거래소를 대리하는 것처럼 오인할 수 있는 행위를 해서는 아니된다.
  4. ④ API 이용자는 성명, 연락처(전자우편 주소 포함)가 변경된 경우에는 이를 한국거래소에 즉시 통보하여야 하며, 변경내용을 통보하지 않아 발생하는 손해에 대하여 한국거래소는 어떠한 책임도 부담하지 아니한다.
제10조(API 서비스의 저작권)
  1. ① 한국거래소가 제공하는 API 서비스 및 관련 프로그램의 저작권은 한국거래소가 보유한다.
  2. ② API 이용자는 API 서비스 이용 시 한국거래소 및 제3자의 저작권을 침해해서는 아니된다.
  3. ③ API 이용자가 API 서비스를 이용한 결과를 사용하여 화면을 제작한 경우, 해당 화면에 “한국거래소 통계정보”를 사용한 결과임을 명시해야 한다. 다만, 한국거래소가 별도의 표시방식을 정한 경우에는 그에 따라야 한다.
제11조(서비스 이용의 제한)
  1. ① 한국거래소는 API 이용자가 관련 법령 또는 본 약관을 준수하지 않는 경우 API 이용자의 사용을 중지할 수 있다.
  2. ② API 이용자는 한국거래소로부터 제공받은 정보를 제3자에게 제공할 수 없다.
  3. ③ API 이용자는 이용기간 만료, 해지 등의 사유로 이용계약이 종료된 이후에는 한국거래소로부터 제공받은 정보를 이용할 수 없다.
  4. ④ API 이용자가 제2항을 위반하였을 경우 한국거래소는 이용승인을 철회하고 API 서비스를 중단할 수 있다.
  5. ⑤ API 서비스 이용상 API 이용자의 귀책사유로 인하여 한국거래소에 손해가 발생한 경우 한국거래소는 본 약관에 따른 계약의 해지와는 별도로 손해배상을 청구할 수 있다.
제3장 기타
제12조(면책)
  1. ① 한국거래소는 API 이용자가 본 약관의 내용을 준수하지 않아 발생한 손해에 대하여 일체의 책임을 부담하지 아니한다.
  2. ② 한국거래소는 정보의 오류, 누락, API 서비스 장애 등과 관련하여 그 정확성과 완결성을 보장하지 아니한다.
  3. ③ API 이용자가 한국거래소 통계정보를 편집하여 새로운 부가정보를 생산한 경우 한국거래소는 해당 부가정보에 대한 책임을 부담하지 아니한다.
  4. ④ 한국거래소는 API 이용자와 제3자간에 API 서비스를 매개로 발생한 분쟁에 대해 개입할 의무가 없으며, 이로 인한 손해배상책임도 부담하지 아니한다.
  5. ⑤ 한국거래소는 통계정보의 계속적 제공 또는 추가되는 통계정보의 지속적 제공을 보장하지 아니한다.
제13조(재판관할)

본 약관에 관한 분쟁이 발생하는 경우 관련 소송의 1심 관할법원은 서울남부지방법원으로 한다.

이 약관은 2025년 12월 26일부터 시행한다.
