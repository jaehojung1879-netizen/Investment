# 사전등록 — industry-alpha-discovery-v1 (Stage B)

**이 문서와 `protocol.json`은 어떤 수익률도 계산하기 전에 커밋한다.** 커밋 해시와 `protocol.sha256`이 그 증거다. 실행은 1회이고, 결과를 본 뒤 정의·문턱·창·틸트·기간을 바꾸지 않는다.

증거 등급: `EXPLORATORY_ON_OUTCOME_EXPOSED_KR_HISTORY`. 2013~2026 한국 가격은 이 저장소에서 이미 여러 번 본 표본이다. 좋은 결과도 전향 검증 전에는 가설일 뿐이다.

## 1. 공통 정의

| 항목 | 정의 |
|---|---|
| 거래일 | KODEX 200(069500.KS) 일별 행 |
| 기준 | KODEX 200 수정종가(분배금 포함 총수익) |
| 바스켓 | 동일가중 매수 후 보유. SEMI = 삼성전자+SK하이닉스, AUTO = 현대차+기아, PETRO = S-Oil+SK이노베이션, SHIP = HD한국조선해양+삼성중공업+한화오션 |
| 체결 | **공표일 다음 거래일 종가**(주). 공표일 종가는 민감도. 공표 전일 종가→공표일 종가는 "발표 반응"(서술) |
| 초과수익 | 같은 구간의 바스켓 단순수익 − KODEX 200 단순수익 |
| 가격 대조 | mom63, mom126 = 체결일 직전 63·126거래일의 바스켓 − 기준 수익(체결일 당일 제외) |
| 비용 | 봉인된 v5 한국 비용: 수수료 1.5bp + 반 스프레드 4bp, 주식 매도 시 연도별 거래세(30→25→23→20→18→15→20bp). KODEX 200은 거래세 없음 |
| 추론 | OLS + Newey-West(lag = ⌈H / 관측 간 거래일 간격 중앙값⌉). ON−OFF 평균차는 이동 블록 부트스트랩(블록 = lag+1, 4,000회). 양측 p |
| 주 가설군 | H1-21, H1-126, H2-126, H2-252. Holm, α=0.05 |
| 보조 가설군 | H2X-AUTO-126, H2X-PETRO-126, H2X-SHIP-126, H3-SEMI-126, H3-SEMI-252. Holm, α=0.05 |
| 추정 불가 | 관측 24개 미만 또는 ON·OFF 각 8개 미만이면 `NOT_ESTIMABLE`. 결과 없음은 반대 증거가 아니다 |
| 독립 관측 수 | n × 관측 간격 중앙값 / H(최대 n)를 모든 검정에 함께 보고 |

## 2. H1 — 관세청 10일·20일 수출 속보의 반도체 서프라이즈

- 표본: KDI 경제정보센터에 있는 10일·20일 잠정치 보도자료 중 "(주요품목) 전년동기대비 반도체(x%)" 문장이 있고, 그보다 먼저 공표된 반도체 증감률이 있는 것.
- **서프라이즈** = 속보 반도체 증감률(공표값 그대로) − 그보다 **엄격히 먼저** 공표된 마지막 반도체 증감률(전월 산업부 월간 최초값, 또는 같은 달 10일 속보).
  - 공개 자료로 만든 기대 대용치다. **시장 컨센서스가 아니다.**
- 회귀: 미래 초과수익(H) ~ ON(서프라이즈>0) + mom63 + LVL(속보 증감률>0). 검정 계수는 ON. 주 지평 21·126거래일, 기대 부호 +.
- 전략(30% 틸트, 주식 노출 항상 100%): KODEX 200 100% / ON이면 KODEX 200 70% + SEMI 30%. 각 속보 다음 거래일 종가에 상태 결정, 다음 속보까지 유지.
  - B0 KODEX 200, B1 상시 ON, P 가격(mom63>0), X 수출 증가율(>0), S 서프라이즈(>0), SP 서프라이즈>0 그리고 mom63>0.
  - **핵심 판정**: S·SP가 P보다 나은가(가격정보 대비 증분).
- 민감도: 삼성전자 단독, SK하이닉스 단독, KODEX 반도체(091160) 바스켓, 공표일 종가 체결, 조업일수 보정 서프라이즈, 10일·20일 분리.

## 3. H2 — 월간 산업부 최초 공표 수출 추세 전환

- 표본: 2013~2026 산업부 월간 수출입 동향(PDF·HWP) 중 반도체 가속도가 공표일 기준으로 계산되는 모든 달.
- **시점 기준 값**: 각 기준월 값은 결정일 이전에 공표된 보도자료 중 가장 늦은 것의 값. 전년 기저는 그 값을 함께 적힌 증감률로 나눈 값, 또는 같은 보도자료가 전년 동월 값을 직접 적은 경우 그 값.
- G3 = (m, m−1, m−2 세 달 합) / (전년 같은 세 달 기저 합) − 1. **가속도** = G3(m) − G3(m−3), 둘 다 같은 결정일 기준.
- 회귀: 미래 초과수익(H) ~ ON(가속도>0) + mom126. 주 지평 126·252거래일, 기대 부호 +.
- 전략(30% 틸트, 월간 결정): B0, B1, P(mom126>0), X(G3>0), A(가속도>0), AP(가속도>0 그리고 mom126>0). 핵심 비교: A vs P, AP vs P, A vs X.
- 다른 산업(보조, 같은 정의를 쓰되 **경제적 기대는 다르다**):
  - AUTO(자동차): + 약함. 환율·해외생산이 이익을 좌우.
  - PETRO(석유제품): 부호 기대 없음. 수출액은 유가의 다른 표현.
  - SHIP(선박): **0, 부정 대조.** 수출은 2~3년 전 수주의 인도 기록이라 이익 인식보다 늦다.
  - 컴퓨터: SSD(메모리)라 SEMI와 같은 정보. 별도 검정하지 않는다.
- 개정 분석: 최신값으로 다시 계산한 G3·가속도의 부호 반전 수, 반도체 최대 개정 날짜.
- 이익 연결(서술): 분기말 달의 G3·가속도와 이후 공개된 삼성전자+SK하이닉스 TTM 영업이익 증가율.
- 가격 반영 진단(서술, 관문 아님): G3 월간 변화를 공표 직전 21·63거래일 SEMI 초과수익으로 설명하는 R².

## 4. H3 — 생산·출하·재고(재고 사이클)

- 표본: 산업활동동향 보도자료 중 업종별 생산·출하·재고 표에서 반도체 행의 전년동월비를 읽을 수 있는 달.
- ISI = 출하 증가율 − 재고 증가율(최초 공표). ON = ISI>0.
- 상태(서술): 재고 정상화(출하>0, 재고<0) / 공급 확대(생산>0, 재고>0) / 수요 약화(출하≤0, 재고>0) / 기타.
- 회귀: 미래 초과수익 ~ ON + mom126, H = 126·252. 보조 가설군.
- **관문**: 파싱된 달이 60개 미만이면 수익률을 계산하지 않고 자료 현황만 보고한다.

## 5. 금지

- 결과를 본 뒤의 문턱·창·틸트·지평 선택, 두 번째 실행, 산업·민감도의 보고 누락, 서프라이즈를 컨센서스라 부르는 것, 승격·운영 변경.

## 6. 결과 전에 이미 알려진 것 (Stage A에서)

- H1: 속보 92건(2021-05-21 ~ 2026-11-11). 126거래일 지평의 독립 관측은 약 7개다. 검정력이 낮다는 사실을 결과 전에 적는다.
- H2: 반도체 가속도가 계산되는 월간 보도자료 119개(2013-07부터). AUTO 119, PETRO 119, SHIP 118.
- **H3: 파싱된 산업활동동향은 50개월이다.** 60개월 관문은 파싱 수를 알기 전에 이 프로토콜에 적었다. 따라서 H3는 `NOT_ESTIMABLE`이고, 보조 가설군의 H3 두 칸은 채우지 않고 Holm 가설군에서 뺀다. 관문을 50으로 낮추지 않는다.
- 개정: 반도체 최초값 대비 최신값 중앙값 0.023%, 최대 1.51%, G3·가속도 부호 반전 0건.
- 입력 파일의 SHA-256은 `protocol.json`의 `dataIdentity`에 있다(Stage A 커밋 `db1bf22`).
