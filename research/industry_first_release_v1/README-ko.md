# 한국 월간 수출 — 최초 공표값과 개정 이력 (2023-08 ~ 2026-10)

**성과 계산 없음.** 이 데이터셋은 "산업 지표를 그날 실제로 알 수 있었던 값으로 쓸 수 있는가"에 답하기 위한 원천 자료다. 수익률, 가격, 모형은 읽지 않았다.

## 원천

- **산업통상(자원)부 "YYYY년 M월 수출입 동향"**(매월 1일 공표) 원본 PDF
  - 받은 경로: KDI 경제정보센터 동향자료(`eiec.kdi.re.kr/policy/materialList.do?topic=O`, 일부 `topic=P`)
  - 받는 방식: 그 사이트의 공개 목록 → 상세 → 첨부 다운로드 링크. 로그인이나 비공개 API는 쓰지 않았고, 요청 간격은 약 1.5초, User-Agent는 일반값이다.
- **부록표 "20(15)대 주요 수출 품목 규모 및 증감률"**(백만 달러)
  - 열 구성: 전년 동월 | 2개월 전 | 1개월 전 | 당월
  - 따라서 한 보도자료가 **당월의 최초 공표값**과 **세 과거 시점의 그때 기준 개정값**을 함께 준다.
  - 6월·12월 합본 보도자료의 누계 열(예: `’25.1.~6.`)은 월 값이 아니므로 버린다.
- **관세청 "월간 수출입 현황 [확정치]"**(매월 중순)
  - 첨부가 HWP뿐이라 파싱하지 않았다. 목록·URL은 `source-manifest.json`에 남겼다.

## 파일 (`data/`)

| 파일 | 내용 |
|---|---|
| `source-manifest.json` | 보도자료별 상세 URL, 공표일, 첨부 이름·바이트·SHA-256. 원본 PDF는 git 밖에 보관한다(34개, 약 60MB) |
| `kr-export-items-by-release.csv` | 보도자료 × 품목 × 표에 적힌 월 × 값(2,125행). `vintage`는 `FIRST_RELEASE`(당월) 또는 `LATER_RELEASE` |
| `kr-export-vintages.csv` | 품목 × 기준월마다 최초 공표값, 1·2·12개 보도자료 뒤의 값, 각 공표일. 아카이브에 없는 시점은 빈칸이다 |
| `revision-summary.json` | 품목별 개정 크기(최초값 대비 %)의 중앙값·최대값과 개정이 있었던 비율 |

## 범위와 결측

- 보도자료 34개(2023-08 ~ 2026-10), 품목 15~20개.
- **결측 보도자료 5개**: 2023-09, 2024-05, 2024-06, 2024-12, 2025-12. 이 아카이브의 두 목록(`O`, `P`)에 해당 월 수출입 동향이 없다.
  - 그 달의 최초 공표값은 비어 있고, 다른 원천으로 채우지 않았다.
  - 개정값은 다음 보도자료의 과거 열에서 대부분 나온다.
- 최초 공표값이 있는 달: 반도체 34개월. 개정 비교 쌍은 +1 보도 29쌍, +2 보도 26쌍, +12 보도 22쌍이다.

## 측정 결과 (개정 크기, 최초값 대비 절대 %)

| 품목 | +1 보도 중앙값 / 최대 | +2 보도 중앙값 / 최대 | +12 보도 중앙값 / 최대 | 개정이 있었던 비율(+12) |
|---|---|---|---|---|
| 반도체 | 0.000 / 0.20 | 0.005 / 0.14 | 0.010 / 0.20 | 59% |
| 자동차 | 0.000 / 0.13 | 0.048 / 0.26 | 0.059 / 0.16 | 82% |
| 컴퓨터 | 0.000 / 0.16 | 0.024 / 0.64 | 0.000 / 0.54 | 36% |
| 석유제품 | 0.20 / 9.5 | 0.97 / 20.2 | 0.92 / 4.2 | 100% |
| 선박 | 0.000 / 0.37 | 0.13 / 10.5 | 0.32 / 12.3 | 95% |

- **반도체 수출액은 최초 공표값이 사실상 최종값이다.** 개정은 잦지만 최대 0.2%다. 이 지표를 과거 날짜 기준으로 쓸 때 개정 누출은 무시할 수준이고, 최초값과 현재값 중 무엇을 써도 결론이 달라지지 않는다.
- **석유제품·선박은 그렇지 않다**(최대 20%, 12%). 이 품목을 쓰는 연구는 최초 공표값을 따로 보관해야 한다.
- 2023-08 이전 아카이브(목록상 2013년부터)도 같은 경로로 받을 수 있다(`--since` 인자). 이번에는 12개월 이상이라는 요구를 넘는 범위까지만 받았다.

## 재실행

```
python -m research.industry_first_release_v1.collect_kr_trade --raw <git 밖 폴더> --since 2023-08
python -m research.industry_first_release_v1.build_revisions
```

- 첫 명령은 이미 받은 보도자료를 다시 받지 않는다(`manifest.json`의 번호 기준).
- `--parse-only`는 받은 PDF만 다시 파싱한다.
- 원본 PDF의 해시는 `source-manifest.json`과 대조한다.
