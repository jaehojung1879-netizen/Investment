# 멀티에셋 결과 보존 상태

요청된 Codex B의12전략 원본은 현재 환경에 없다:

* `/workspace/multi-asset-b/report.md`
* `/workspace/multi-asset-b/all-metrics.csv`
* `/workspace/multi-asset-b-results.tar.gz`

따라서 2016-11-09~2026-09-14/2472일, SPY CAGR15.37%·MDD−33.69%, 목표변동성10% CAGR10.98%·MDD−13.05%라는 전달 수치는 **사용자 제공 요약이며 원본 재검증 성공이 아니다**. NAV·비용·입력 버전·6/12개월 구간 성과·회복기간·통계적 우월성을 확인하지 못했다. 새로운 계산이나13번째 전략은 수행하지 않았다. 원본을 확보하기 전에는 위험 감소를 수익·통계 우월성으로 승격하지 않는다.

별도로 실제 남아 있던 **이전 Codex A** 산출물의 자체 코드·보고서·집계 결과22파일을 정확한 바이트와 SHA로 보존했다. `legacy-codex-a-code-and-summaries.tar.gz`와 `preservation-manifest.json`에 있다. 이는 C2 요약/공개 팩터/2025년 US ETF 탐색 등 다른 연구이며, 누락된 Codex B12전략으로 대체하지 않는다. 이번에 재계산하지 않았다.

공급자 원본·가격·분배금 파일과 일별 NAV/시계열 파일은 업로드하지 않았다. 아카이브에 기존 입력 버전의 해시 목록은 있지만 전체 입력이 포함되지 않으므로 완전한 원본 재현 패키지라고 주장하지 않는다. 원본 데이터 재배포 권리가 확인되지 않은 상태에서 원래15MB 수집 ZIP 전체를 올리지 않았다.

보존물 검증은 tar 멤버별 bytes/SHA 및 허용 파일 목록을 확인한다. 보존 스크립트는 파일만 읽고 압축하며 전략·통계 계산기를 실행하지 않는다.
