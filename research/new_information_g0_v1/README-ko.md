> **상태: SOURCE_AUDIT_IN_PROGRESS / OUTCOME_BLIND**. 기존 수익률·IC·NAV·향후 가격 라벨·포트폴리오 계산 0회. 이 문서는 투자전략 사전등록도, 통과 판정도 아니다. 연결: Issue #371.

- #360: 수출액 135개월, 관세청 속보 92건, 산업활동 50개월 조사. 수출액 가속도 4개 주 가설 모두 미지지. 단가·재고 원천이 별도의 신규 정보인지 조사할 필요만 남았다.
- Codex 뉴스심리: 가격·변동성 매칭 후 초과 정보 미확인; PIT 적격 사건 0. 매수 신호 승격 금지.

## G0 원천 데이터 계약

필수 원공시 열:
- original_document_id = rcept_no; issuer = corp_code; reported_date = rcept_dt; source_url; original_sha256.
- published_at_exact = NULL (공식 목록의 날짜만으로는 시각 불명).
- available_from = NEXT_XKRX_SESSION_AFTER_CONFIRMED_PUBLICATION (현재는 미확정). 공시 이전 거래일 사용 절대 금지.
- filing_regime = PRE2020 / POST2020_PRE2022 / POST2022_PRE2026 / POST2026_INTERPRETATION (각 변경의 실제 시행일 확인 전에는 근사 구간 라벨).
- correction_chain_id / original_prior_rcept_no / same_owner_identity / report_type / state_before / state_after / change_evidence_offset.
- state_* 는 보고자 본문과 직전 유효 본문을 검증한 경우만 채움. 키워드 추정, report_resn만의 추정은 NULL.
- 금지: 미래 공시로 과거 보유목적 덮어쓰기, 최신 정정본문의 과거 사용, 복수 특별관계자 중복, 종결 기업 배제, 원자료 없는 원문 텍스트를 실제 사건이라고 추론.

## G0 표본 원칙과 통과 조건

1. 코드의 첫 기술 probe는 각 D001/D002에 **2019-05, 2020-05, 2022-09, 2024-05, 2026-05**의 5개월만, 월별 첫 목록 페이지(100건)만 조회. 전수 조사 아님. 원문 최대 각 6건. 원문은 SHA와 '보유목적' 텍스트 존재 여부만 기록하며 수익/의미를 판정하지 않는다.
2. 먼저 소표본에서 공시 원문을 파싱·대조할 수 있는지 확인. 불가능하면 확장 수집 중단. 샘플이 편향되기 때문에 첫 페이지 접수번호만으로 **사건 발생률/검정력 계산 금지**.
3. 통과 시 별도 층화 표본 설계: 법령 구간·보고유형·업종·발행사·정정 유형별. 원문 2인 검증 또는 원문/자동 파서 비교, 정확도와 누락률을 기록. **애매한 문서 제외가 결과 의존적으로 이뤄지지 않게** 사전에 원칙 고정.
4. 전체 모집단의 `독립` 보고자×발행사×사건 군집과 연도별 밀도가 확인된 뒤에만 MDE를 계산. 반복 변경은 중복을 제거하거나 군집. 동시에 발생한 같은 시장 충격은 달력 시간 단위 군집을 추가.
5. G0 PASS_TO_PREREG는 (i) 원시 최초 공개 검증 (ii) 이전 목적과 이후 목적을 실제 파싱 (iii) 충분한 독립 사건 및 경제적 효과에 대한 파워 (iv) 종결대가·업종·시총·유동성 대조 가능성 (v) 기존 K9·단일 내부자 매수와의 중복분해를 모두 충족할 때만 가능.
6. 결과 미리보기 후 유리한 목적 전환, 시점, 업종을 고르는 행위 금지.
