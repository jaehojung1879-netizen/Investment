# 차세대 연구 우선순위

## 1. 중심 질문과 세 계층

"산업과 기업의 미래를 예측할 수 있는가"가 아니다.

**"그 미래에 대한 시장의 기대와 실제로 관측되는 변화 사이에 투자 가능한 차이가 있는가"**를 묻는다.

| 계층 | 무엇을 재나 | 이 저장소의 현황 |
|---|---|---|
| 1. 산업의 실제 변화 | 제품가격·스프레드, 재고·회전, 생산·가동률·설비투자, 수주·출하, 수출 물량·단가, 증설·감산, 선도기업 실적, 공급망 확산 | 설비투자(#355)와 잠정실적(#310)만 사용. 외부 실물 통계는 0 |
| 2. 시장에 반영된 기대 | 당시 애널리스트 추정치·수정·분산, 주가에 반영된 성장 기대, 밸류에이션, 발표 전후 반응 | 추정치는 SOURCE_BLOCKED. 대용은 발표 반응(#354)과 가격 수준뿐 |
| 3. 투자 의사결정 | 선택·매수 시점·대기·보유·축소·ETF 대체 | 선택(대부분 A), 매수 시점(#355 S2), 축소(#355 S3) 일부 |

**규칙**
- 계층 1의 변화가 계층 2의 기대와 다를 때만 수익 기회가 생긴다는 것이 이 프로그램의 가설이다.
- 계층 2를 직접 관측하지 못하면 가격 기반 대용을 쓴다. 다만 그 결과는 `EXPECTATION_PROXY_NOT_OBSERVED`로 표시하고, 실제 기대치를 관측한 결과와 섞지 않는다.
- 계층 3의 각 결정에는 반사실 대조군이 하나씩 붙는다.

| 결정 | 대조군 |
|---|---|
| 선택 | 같은 업종·규모·수의 무작위 |
| 매수 시점 | 같은 종목·같은 비중·같은 종료일 |
| 축소 | 같은 시점·같은 금액의 무작위 또는 비례 축소, 모멘텀 매칭 |
| ETF 대체 | 같은 주식 비중의 ETF |

## 3. 순서와 이유

1. **지금**: N2(전향 스냅샷)와 N1의 착수 조건 1~3(원천 실측·개정 폭·중복 측정)
   - 수익 검정 없이도 남는 것이 있다. 이것이 없으면 계층 1 연구 전체가 PIT 근거 없이 진행된다.
2. **조건부**: N3(#310 H2)
   - 데이터와 계약이 이미 고정돼 있어 비용이 가장 작다.
   - Phase D 예외라 사용자 승인이 먼저다.
3. **조건부**: N4 — 최소 탐지 효과를 먼저 계산하고, 의미 있는 크기를 탐지할 수 있을 때만 진행한다.
4. **보류**: N5·N6(재측정·재포장 위험), N7(데이터 구축 비용 대비 가치는 N1 이후 재평가), N8·N9·N10(데이터 차단)

## 4. 투자 가능 종목군 확대 타당성 (과거 성과는 계산하지 않음)

| 항목 | 한국 121~300위 | 미국 중형주(S&P 400) |
|---|---|---|
| 당시 구성 | KRX 일봉 원장에서 시총 순위 재구성 가능. 월평균 196개가 일평균 거래대금 10억 원 기준을 넘음(v2.54) | 무료 PIT 구성 원천 없음. `datasets/s-and-p-500-companies`는 500만 다룬다 |
| 과거 가격 | KRX Open API `sto/stk_bydd_trd`는 서비스 승인됨(vendor-refusal 기록) | Yahoo는 상장폐지 종목을 주지 않음 |
| 재무 | DART. 335종목 미수집, 약 4.8만 호출·33회 실행 추정(v2.54) | Finnhub(현 커버리지 미확인) |
| 상장폐지·정지 | 상장폐지 22종목 종결 대가도 아직 미해결(v2.28~v2.29). 확장 시 늘어난다 | 없음 |
| 식별자 | 종목코드 + DART 고유번호(기존 해석기 재사용) | CIK·티커 재사용 문제(v2.27과 같음) |
| 유동성·비용 | 거래대금 원장 있음(대용, v2.54) | 없음 |
| 업종·규모 대조군 | 업종 라벨 없음(v2.54) | — |
| **판정** | **데이터 구축 가능, 비용 큼.** N1 이후 재평가 | **무료로는 불가.** 유료 결정 대상 |

"중형주에서 정보 비효율이 크다"는 연구 가설이다. 이 저장소에서 입증된 사실이 아니다.
