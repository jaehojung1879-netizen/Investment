# alpha-mechanism-sprint-v1 — 한국 잠정실적 공시: 새 정보인가, 6~12개월 알파 후보인가

**결론 먼저.** 세 후보 중 실제로 새로운 관측 정보이면서 지금 계산 가능한 것은 **한국 DART 영업(잠정)실적(공정공시)** 하나뿐이었다.
원천은 실재하고, PIT로 쓸 수 있으며, 기계로 읽을 수 있다. PIT Top120 멤버 발행사-분기의 **79.62%**에 정식 보고서보다 앞선 잠정실적이 있고,
선행 시간은 중앙값 **12 KRX 영업일**이다. 그러나 이 공시가 담은 숫자는 나중에 나온 정식 보고서 숫자와 **97.5%가 1% 이내로 같다**
(매출, 2,078건). 6~12개월 지평에서 새로 생기는 것은 **같은 회계 숫자를 12영업일 일찍 안다는 시점 이점**뿐이다. 같은 회계 정보의 정식 보고서 버전은
Phase C 회계 가족과 실적 가속 연구에서 이미 증거 없음으로 끝났다.

수익률은 **한 건도 읽지 않았다.** 한국 역사 성과 평가는 Phase D 종료 계약으로 막혀 있다. 따라서 이 스프린트는 예측력이나 ETF 대비 우위를 측정하지 않았고,
측정했다고 주장하지 않는다. 판정은 사전 기록한 게이트대로 `ELIGIBLE_FOR_PROSPECTIVE_REGISTRATION_ONLY`다. 다만 전향 검증의 검정력은 사실상 없다.
H126 상·하위 삼분위 차이 4%p를 잡으려면 **11~34년**이 필요하다. **6~12개월 종목선택 후보로서는 종료를 권고한다.** ETF 100% 기본값은 그대로다.

- 증거 등급: `OUTCOME_BLIND_SOURCE_ELIGIBILITY`. 수익률 0건, 라벨 0건, 모형 적합 0건(`results.json`의 `returnsRead`, `labelsBuilt`, `modelsFit`).
- 사전 프로토콜: [`PROTOCOL.md`](PROTOCOL.md). 원천 수집 전 커밋 `05a2674`에 고정했다.
- 기계 판독 결과: [`results.json`](results.json), sha256 `48d24279…e93e0f`. 같은 입력으로 두 번 실행해 바이트가 같은 것을 확인했다.

## 5. ETF 대비 의미 있는 우위가 발견됐는가?

**아니다. 측정하지 않았고, 측정할 수 없었다.** 069500.KS 대비 순수익, IC, 회전율, 집중도, 하방위험은 모두 `null`이다.
KR 역사 성과 평가는 Phase D 계약상 소유자 예외 없이 열 수 없고, 이 스프린트는 그 제약을 우회하지 않았다. 미국 동등 원천은 차단돼 있다.
"우위 없음"이 증명된 것도 아니다. 다만 사전 근거는 약하다.
① 내용이 정식 숫자와 같다(97.5%). ② 그 정식 버전은 Phase C와 실적 가속 연구에서 증거가 없었다.
③ 새로 생기는 것은 H126의 약 9.5%, H252의 약 4.8%에 해당하는 12영업일 시점 이점이다.

## 6. 계속할 이유가 있는가?

**6~12개월 종목선택 후보로는 종료를 권고한다.** 역사 검정은 거버넌스로 닫혀 있다. 전향 검정은 실용적 효과 크기(H126 4%p)를 검출하는 데 10년 이상 걸린다.
이 결론을 바꿀 수 있는 결정적 증거는 두 가지뿐이다.

1. **소유자의 Phase D 예외 승인 아래 단 1회 역사 검정.** 같은 분기 실적 변화 신호를 두 시점에 쓰는 짝 비교다. 하나는 잠정 접수일 다음 세션 종가 진입, 다른 하나는 정식 보고서 접수일 다음 세션 종가 진입이다.
   같은 종목·같은 H126/H252 지평에서 두 신호의 차이만 측정하면 "시점"이라는 유일한 새 요소를 분리할 수 있다. 차이가 0을 포함하면 이 원천은 6~12개월 지평에서 완전히 닫힌다.
2. **접수 시각 원천(KIND 등)의 확보.** 시각이 있으면 다른 질문이 열린다. 발표 반응·단기 표류(H21~H63) 설계로, 6~12개월 질문과는 별개다.

그때까지 운영 판단은 바뀌지 않는다. 두 지역 모두 **ETF 100%**(`PASSIVE_NO_DEFENSIBLE_EDGE`)를 유지한다.

## 재현

환경에 `DART_API_KEY`가 필요하고, 키는 어떤 파일에도 기록되지 않는다.
`signal-history@5d187ec1`에서 `ledger/universe/kr/*`, `ledger/dart-ownership-events/{collection-universe.json,dart-ownership-*.jsonl.gz}`,
`ledger/fundamentals/kr-candidate-merged/dart-*.jsonl.gz`, `ledger/kr-investor-flow/manifest.json`을 꺼내 둔다. 해시는 `results.json`의 `sourceHashes`에 있다.

```bash
D=research/alpha_mechanism_sprint_v1
python $D/collect.py --universe <collection-universe.json> --out $D/data/dart-list            # list.json, 1,433 calls
python $D/analyze.py ... --write-full-plan plan.json                                           # 멤버 단위 잠정실적 원본 목록
python $D/sample_docs.py --plan $D/data/prelim-docs-member-units-plan.json.gz \
       --out $D/data/prelim-docs-member-units.jsonl.gz --first-confirmed-per-unit --workers 6  # document.xml
python $D/analyze.py --universe-dir <universe> --collection-universe <cu.json> --dart-list $D/data/dart-list \
       --merged-dir <merged> --sample $D/data/prelim-doc-sample-parser-v1.jsonl.gz \
       --doc-parses $D/data/prelim-docs-member-units.jsonl.gz --ownership <own/*.gz> \
       --investor-flow-manifest <manifest.json> --out $D/results.json
python -m pytest -q $D/test_sprint.py                                                          # 네트워크 없음, 합성 입력
```

`data/prelim-docs-member-units.jsonl.gz`는 서버가 준 바이트의 sha256과 결과 표 본문을 함께 보존한다. 그래서 파서를 고쳐도 다시 내려받지 않고 재파싱할 수 있다.
