# alpha-mechanism-sprint-v1 — 사전 기록 프로토콜 (원천 수집 전 작성)

**작성 시점:** 2026-11-01, DART 원천 수집·분석 코드 실행 **전**. 이 파일은 수집 전 커밋으로 고정하고 이후 수정하지 않는다.
**증거 등급:** `OUTCOME_BLIND_SOURCE_ELIGIBILITY` — 미래 가격·수익률·라벨·모형 예측을 읽지 않는다.

## 1. 선택한 후보와 이유 (요약)

후보 A(실적 정보 전파)의 유일한 비중복 관측 정보는 **한국 DART 영업(잠정)실적(공정공시)** 이다.
정식 분기·반기·사업보고서보다 먼저 접수되는 잠정 매출·영업이익·순이익과 그 전년동기 대비 변화다.
Phase C의 회계 가족(C·B·J01)은 정식 보고서 접수일 이후에만 보이는 값이었고, `J01_periodicFilingEvent`는 BLOCKED였다.
후보 B(산업 내 선도→후발 확산)는 KR에서 X3·A09·A10·H01·H03·H07로 이미 측정됐고 Phase D로 KR 역사 탐색이 종료됐으며,
미국은 시점별 산업 분류가 차단돼(#290) 독립 가설이 성립하지 않는다. 후보 C(투자자 수급)는 KRX 투자자별 거래가
`HTTP 400 LOGOUT`으로 0건이고(재프로브 금지), DART 대량보유는 2024-09-24부터라 6~12개월 성숙 표본이 부족하다.

## 2. 거버넌스 제약

`docs/kr-alpha-research-final-development-assessment.md` §7은 한국 역사 탐색을 종료했고 새 정보축은
"독립적인 새 사전등록과 시점별 기록만" 검토한다. 따라서 이 스프린트는 **한국 과거 수익률을 읽지 않는다.**
허용 범위는 (1) 새 원천의 적격성 측정, (2) 기존 연구의 사후 기술진단(결과 미접근)이다.
`docs/research-program/01-methodology-evidence-ko.md` §C의 기존 중단 규칙
("KR 잠정실적 공시의 커버리지·시각 정밀도 감사만 먼저. 커버리지 <60% 또는 시각이 장중/장후 구분 불가하면 중단")을 그대로 적용한다.

## 4. 분류 규칙 (보고서명 정확 패턴, 내용 추측 없음)

- `PRELIM`: 보고서명에 `영업(잠정)실적`을 포함. `[기재정정]` 접두는 정정으로 분리.
- `PNL_CHANGE`: `매출액또는손익구조` 포함(수시공시, 연간 손익 30%/15% 변동). 별도 집계.
- `GUIDANCE`: `영업실적등에대한전망` 포함(전망 공시). 별도 집계.
- `FORMAL`: 정기공시 중 `분기보고서`/`반기보고서`/`사업보고서` + `(YYYY.MM)`; 정정 제외, 기간은 보고서명의 `(YYYY.MM)`.
- 잠정 공시의 분기 배정: 접수일 직전에 끝난 달력 분기말. 정정 아닌 최초 접수만 사용. 표본 문서 파싱으로 배정 정확도를 검증한다.

## 6. 판정 (사전 고정)

- G1 실패 → `SOURCE_INSUFFICIENT`.
- G1 통과, G3 실패(중앙값 ≤ 5영업일), G6 대부분 일치 → `TIMING_ONLY_NOT_INDEPENDENT_FOR_H126_H252`: 6~12개월 지평 후보 종료.
- G1·G3·G4 통과 → `ELIGIBLE_FOR_PROSPECTIVE_REGISTRATION_ONLY`: 한국 과거 성과 검정은 거버넌스상 차단(소유자 예외 필요),
  전향 기록 등록 후보로만 남긴다. 최소 유효 표본·기간을 함께 계산한다.
- 어떤 경우에도 신규 OOS·알파 주장 없음, 수익률 0건 열람.

## 7. 최소 유효 표본(사전 고정 계산식)

H126/H252 삼분위 상·하위 평균 차이의 검출 가능 최소 효과(MDE, 양측 5%, 검정력 80%):
MDE = 2.802 × σ × sqrt(2/n_tercile) × sqrt(1 + (n_tercile−1)·ρ) / sqrt(K_eff)
σ = Phase C 최종 문서의 B0 MSE 제곱근(H126 0.093059 → 0.305, H252 0.346663 → 0.589; 이미 공개된 값, 새 수익률 미열람),
ρ = 동일 시점 종목 간 평균 잔차 상관 0.05(가정, 명시), K_eff = 비중첩 코호트 수(H126: 연 2, H252: 연 1).
