## 2. 방법 — 정확한 3항 분해

보유기간(실행 종가 → 다음 실행 종가)마다 각 종목 비중 w의 ETF 대비 초과수익을 정확히 세 항으로 나눈다.

```
R_i − R_m = (β_i − 1)(R_m − R_f)                      MARKET_BETA      ETF 대비 베타 노출
          + [R_I − R_f − β_I (R_m − R_f)]             INDUSTRY_ALPHA   보유 산업 바스켓의 베타조정 수익
          + [R_i − R_I − (β_i − β_I)(R_m − R_f)]      SELECTION_ALPHA  같은 산업 바스켓 대비 종목
```

- **β**: 신호일의 F03_beta252(PIT)
- **I**: 신호일 PIT 산업. 품질 적격 구성원을 시총(구성 스냅샷, 신호일 이전) 가중한다.
- **ETF / 현금 다리**: ETF는 0, 현금은 β=0
- 행마다 항등식을 단언했다(최대 잔차 5.6e-17).
- 산술 합과 CAGR 차이의 간극은 **복리 항**이다.
- **비용**: 고정 엔진을 비용 0/1로 두 번 돌린 차이
- **엔진 잔차(MECHANICS)**: 정지 종목 잠김, 종결 0원 처리처럼 목표 장부와 실제 엔진이 갈라진 부분. 사건별로 이름을 붙였다.
- **닫힘**: 순 초과 CAGR = 베타 + 산업 + 선택 + 엔진 잔차 + 비용 + 복리. 최대 잔차 3.6e-17.

**SMS 슬리브 층**
- 각 기간에 고른 슬리브 수익 − 4개 슬리브 평균 = **선택가치**. 같은 3항으로 다시 나눴다.
- 귀무: 무작위 슬리브(균등)와 선택 순서 섞기 10,000회
- 같은 평균 노출 쌍둥이와도 비교했다.
