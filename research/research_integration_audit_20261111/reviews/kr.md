네 위상의 ETF 대비 CAGR 차이는 **-9.3955 / +2.5767 / -2.3674 / -5.0876pp**다. 위상 0 순 CAGR 7.5621%, MDD -63.2100%다. 원 토너먼트의 23.3%는 다른 시작기간(2016년부터)의 결과이므로 이번 2018년 시작 수치와 직접 동렬 비교하면 안 된다. 보고서의 “위상 1이 원 토너먼트 연도별 경로를 재현” 주장은 해당 위상의 연도별/일별 장부가 이번 커밋에 없으므로 본 감사에서 독립 확인하지 못했다.

## 4. PIT·자료 계보의 우선 문제

**P1 — 직접 보류와 특성 원천 정정은 다르다.** `run.py:38-58`은 기존 `dataset.pkl`/`matrix.pkl`을 읽고 최종일 종가 235개와 `b08Confirmed`만 결합한다. 기록된 matrix digest는 원래 Phase B `32e49b57…`다. `cocktail.py:118-130`의 006800 보류는 **선정에서만** 제거하며, 그 종목이 이미 들어간 금융업 H01 등 업종 특성·순위를 다시 만들지 않는다. 보류 예상 선택은 전체 슬리브 역사에서 S1 1회, S2 0회, S3 5회다. 이 횟수만으로 간접 업종 특성 영향까지 작았다고 할 수 없다.

같은 HEAD의 Phase C 입력 v2/후속 006800 복구는 다른 계보다. 전기간 가격 보류 상태에서는 금융업 H01/H08 **13,465 member-date**가 원래 행렬 대비 관측을 잃었고, 원천 구간 복구 후에도 2018년 권리락 경계 통과 **785행**은 여전히 결측이다. 복구 행렬 digest는 `c3d66a99…`다. 공식 2018-01-23 비상장 우선주 청약권 가치 미확정 경계를 연결하지 않고, 2026년 주식배당 권리는 현금과 별개로 처리한다. 근거: `mirae-source-recovery/validation.json`, `006800-source-correction.json`, `pipeline/kr_alpha_atlas_mirae_repair.py:111-141`.

따라서 cocktail은 **정정된 Phase C v2 입력으로 수행된 연구가 아니다**. 보고서 §1의 “정정 ML 토너먼트 v2 없음”은 별도의 ML 토너먼트 버전을 말하므로 Phase C v2의 존재와 직접 모순이라고 판정하지 않는다. 필요한 조치는 계보·한계의 명확한 표기이며, 이 감사에서 어떤 연구도 재실행하지 않는다.

**P1 — 관측일 지연은 진짜 발표 빈티지 인증이 아니다.** `cocktail.py:38-45`는 관측일<=D-지연일의 과거 값만 merge-asof하고, FRED 4일/H.10 8일 지연을 적용한다(`cocktail.py:69-91`). 훈련은 label exit<D(`run.py:148`)이고 대체·표준화도 훈련 행만 사용한다(`run.py:158-166`). 코드상 미래 관측일/미성숙 라벨 제한은 타당하다. 다만 실제 발표 시각·ALFRED vintage·vendor 정정 이력·전체 공시 원행은 본 감사에서 인증하지 못했다. H05/H07의 2018~26 관측률도 **53.68%/44.73%**라서 입력 평균 대체에 의존한다. 저장 카나리아/합성 테스트는 이런 원천 빈티지를 증명하지 않는다.

**P2 — 독립 추론 재현에 필요한 중간자료가 없다.** `run.py:470-471`은 일별 NAV·상태·보유·슬리브를 scratch의 `cocktail-eval.pkl`에만 쓴다. 커밋에는 그 파일과 OOS 예측/성숙 라벨 원행이 없다. 따라서 이번 검산은 저장 집계 산술, 소스 정의, 코드 통제의 확인이고 모든 NAV·CI·OOS R²의 독립 재현은 아니다. 저장 `verification.json`의 rechain 차이도 32.45→약33.0%처럼 근사 비교이며 완전 경로 동일성 시험이 아니다(`verify.py:26-35,50-52`).

**P2 — 분해값 표현 주의.** `run.py:240`의 이름 `grossCagrGap`은 실제로 비용을 이미 낸 `sims` NAV로 계산된다(`run.py:369-370`). +17.9363pp는 순 CAGR 차다. 슬리브 시점 효과 +17.6293pp와 잔차 회귀는 설명 통계이며, 잔차를 독립적 알파로 해석할 수 없다. 비용2배 민감도는 평가 거래 비용만 늘리고 슬리브 과거 NAV/학습 라벨의 비용은 기본값을 유지한다(`run.py:93-96,259,285`); 특히 전략 모멘텀의 비용 상승 후 신호 피드백까지 재계산한 스트레스는 아니다. S2 단독 비용 민감도 해석에는 이 선택 피드백 문제가 없다.
