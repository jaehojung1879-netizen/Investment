# 한국 DART 임원·주요주주 장내 현금매수

**판정은 자료로 판별 불가다.** 공식 D002 검색은 32개월·32,986건의 전체 페이지를 확인했다. 당시 적격 후보에게 필요한 상세 문서 6,574건 중 96건을 읽었다. 완결된 주간 투자 신호는 0주다. 유일하게 원문이 겹친 2023-01-06 판단의 일부 기간에서만 5종목 대조를 계산했다. 이 표본에서 비용 차감 선택 효과는 6·12개월 **+1.19/+0.60%p**였고 KODEX 200 대비는 **−1.01/−0.27%p**였다. 주 전체에 대한 수익, 신뢰구간, 검정 및 반복 운용 성과는 미측정이다. ## 2023-01-06 일부 공개 구간 진단

## 공시 시점과 관측 범위

- OpenDART의 `elestock.json`은 보고 관계와 소유 요약을 제공하고, 공시일에 대응하는 거래 사유·개별 수량·단가는 D002 원문에서 확인한다. 이 환경에서 인증키가 확인되지 않아 공식 DART 공개 검색과 문서 뷰어를 사용했다. 적격 보고자 범위는 금융감독원의 D002 공시 유형을 따른다. 별도의 거래계획 D005는 예정 내용을 싣기 때문에 실제 유상 매수로 집계하지 않았다. [임원·주요주주 요약 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS004&apiId=2019022) · [공시 목록 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001) · [금융위 거래계획 제도](https://www.fsc.go.kr/no010101/82635)
- 공식 DART 목록의 날짜를 최초 공개일로 썼고 공개 시각이 없어서 다음 정규 거래일 종가부터 사용했다. 6,574개 대상 행 중 52개에서 공시 목록의 표시일과 접수번호 날짜가 달랐다. D002 상세의 `변동일`은 장내 거래의 계약결제일이므로 결제일 필드로 따로 저장했다. 체결 날짜·시간이 확인되지 않은 행은 `transactionDate`를 빈 상태로 둔다. [공식 원문 표본](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260911000220) · [원천 검증 영수증](inputs/KR/dart-probe-manifest.json)
- 정정을 포함한 공시 목록 32개월을 페이지별 총수와 접수 ID로 검산했다. 전체 목록이 날짜 경계를 덮는 판단은 138/454주다. 적격 종목에 해당하는 6,574건 중 96건은 세부 표를 읽었고, 메인 221건과 상세 2건의 시도는 HTTP 503으로 실패했다. 6,255건은 중단 시점에 미수집이었다. 원문 단건 재시도와 2022-12-29~31 경계의 단건 목록도 503이었다. 138주를 전수 목록 관측 증거로만 사용했으며, 공시 자체가 미확보인 구간은 무신호로 채우지 않았다. [공시별 상태](results/KR/receipt-audit.csv.gz) · [다음 복구 범위](results/KR/minimum-missing-2023-01-06.csv)
- 확인한 96문서의 919개 세부 행에서 보통주, 양의 수량·단가, 명시적으로 장내매수인 신호는 398개 최초 공개 행, 14개 공시, 12개 발행사였다. 매수 아닌 438행, 보통주 외 28행, 기업행위 2행, 거래 유형 또는 유상 여부 미확인 53행을 분리했다. 원문에서 연결이 확인된 정정만 처리하고 새 내용은 새 공개일부터 사용했다. 동일 발행사·결제일·보통주·수량·단가·기초/기말 수량이 동일하면 중복 경제 거래로, 해당 판단일의 발행사는 1회로 집계한다. 확인할 원문이 없는 정정은 대조군 근거에서도 제외한다. 삭제 공시와 원문 미확보 정정의 과거 전체 상태는 확인할 수 없다. [거래행별 판정](results/KR/transaction-audit.csv.gz)
- 5% 외부 대량보유 D001 계열은 기존 `majorstock.json` 수집 원본 2,496건, 조회 발행사 254개, 관측 2024-09-24~2026-09-23을 확인했다. 별도 원천 재고이며 확인 유형·시장·거래일·단가가 부족하여 이번 D002 추정에 들어가지 않는다. ## 재실행과 필요한 추가 원본

아래 명령은 저장한 32개월 페이지 영수증, 발행사 이력, 확인된 DART 거래행과 #352 가격·비용 입력으로 결과를 다시 만든다.

```bash
PYTHON=/workspace/s2-venv/bin/python bash research/kr_us_public_buys_v1/reproduce.sh KR
```

새 원천을 받는 순서는 아래와 같다. 공개 목록과 원문 바이트는 `/workspace/public-buys-inputs/kr/lists/`, `/workspace/public-buys-inputs/kr/docs/`, 해석 검산은 `parsed-lists/`, `parsed-docs/`에 둔다. 보존한 원문을 압축 해제한 SHA-256과 요청 URL은 입력 패널에 있다. 원시 HTML에는 신고자 정보가 들어 있어 커밋된 패널에는 원문 요청 정보·해시와 거래 분류에 필요한 필드만 둔다.

```bash
python -m research.kr_us_public_buys_v1.kr_collect lists --start-month 2023-01 --end-month 2025-08
python -m research.kr_us_public_buys_v1.kr --stage plan
python -m research.kr_us_public_buys_v1.kr_collect docs --workers 1 --pace 1.0
python -m research.kr_us_public_buys_v1.kr --stage freeze
python -m research.kr_us_public_buys_v1.kr --stage run
```

보조 한 주의 전체 공개 창을 확인하려면 2022-12-29~31 공식 D002 목록과 그 목록 중 당시 적격 발행사의 원문이 필요하다. 이 경계는 공개 DART 수집 명령에서 `--start-month 2022-12`를 주어 복구할 수 있고, 계획 생성에도 같은 시작월을 전달한다. 2023-01-05 목록 안에서 이미 특정한 여덟 후보 `002790.KS`, `005380.KS`, `036460.KS`, `047050.KS`, `064350.KS`, `066570.KS`, `096770.KS`, `302440.KS`의 21개 원문도 필요하다. 저장 경로는 `docs/<접수번호>-main.html.gz`, `docs/<접수번호>-detail.html.gz`와 `parsed-docs/<접수번호>.json`이다. 기존 인증 환경이 있다면 OpenDART의 `list.json`에 `pblntf_detail_ty=D002`, 원본 ZIP API `document.xml`에 해당 접수번호를 사용해 같은 최소 자료를 복구할 수 있다. 6·12개월 검정에는 거래와 매칭이 성립하는 유효 주가 각각 최소 50·100주 필요하다. [특정한 미확보 접수번호](results/KR/minimum-missing-2023-01-06.csv) · [OpenDART 원본 ZIP 안내](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)
