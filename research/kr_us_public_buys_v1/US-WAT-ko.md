# 미국 시총 입력의 공시 대조와 장부 영향

원 판단일·가격·비용과 #351 장부, #352 만기 코호트를 재사용했다. 종목별 인접 유효 관측이 28일 이내일 때 주식 수·시총의 5배 이상 규모 변화, 원 종가에서 분할 근처의 가격 변화, B·U1 목표 비중의 5%p 이상 변화 또는 10% 이상 집중을 기록했다. 플래그에서 공시 원문으로 원인을 확인할 수 있는 행을 별도 사본에서 바꿨다. [사전 설계](DESIGN-ko.md)

## 공통 입력 검사의 확인 범위

|항목|원 검출 건|출처 대조|
|---|---:|---|
|주식 수 인접 규모 변화|66건, 41종목|35건은 전후 어느 한쪽의 수량을 공시로 정정했다. 16건은 이전 91일의 분할 배율과 맞았다. 15건은 추가 원자료가 필요하다.|
|시총 인접 규모 변화|46건, 22종목|35건은 전후 어느 한쪽의 수량을 공시로 정정했다. 11건은 미확인이다.|
|거래 기준 종가 인접 규모 변화|20건, 18종목|17건은 같은 구간의 분할 배율을 되돌리면 ±20% 안에서 맞았다. 3건은 미확인이다.|
|기존 분할 보류 구간|1,350 이름×주|양의 시총 입력을 승인한 행은 0건이다.|
|목표 비중 주간 변화 ≥5%p|B 7, native U1 88, U1 20% 혼합 3, U1 직접복제 조달 7|원 목표와 직전 목표를 그대로 보존했다. 목표 변화만으로 입력 오류로 판정하지 않았다.|

WAT 이외에서 SEC companyfacts의 `dei` 후보 1,018개 종목-주를 74개 원 공시와 다시 대조했다. 최종 승인에는 기계 판독 수치와 당시 문서의 표지 표시가 일치하거나 같은 기준일의 공시 본문이 동일한 수량을 입증해야 했다. 이 검증으로 초기 정정 후보 1,035행에서 92행을 추가 보류했다. 최종은 WAT 외 68개 공시의 917행과 WAT 26행으로 **14종목·943행**이다. 같은 CIK·접수 번호·시각의 표지 수를 썼으며 주식 수 기준일 이후 확인된 분할과 적용 시점의 정규 종가도 검산했다. ## 재실행

저장된 SEC 정규화 입력부터 시총·장부·검산을 재계산한다. 원 가격·피처 경로는 `/workspace/batch-inputs/us/{close.pkl,features.pkl}`, 정정 가격·어댑터는 `/workspace/exposure-inputs/us/{close-repaired.pkl,us-adapter-payload.pkl}`이다. 정정 가격은 #351의 FISV 한 셀 사본이다. [#351 입력 복구 경로](../kr_us_exposure_preserving_v1/US-INVENTORY-ko.md)

```bash
export OPENBLAS_NUM_THREADS=1
python -m research.kr_us_public_buys_v1.wat
python -m research.kr_us_public_buys_v1.wat_resolution
python -m research.kr_us_public_buys_v1.wat_verify
```

SEC 원문 단계부터 확인하려면 `wat_sources`와 `wat_review`에 `--fetch`, `wat_audit`에 `--fetch-companyfacts`를 준다. 저장소 밖 `/workspace/wat-sec-inputs` 아래 원 HTTP 응답 사본을 우선 사용한다. 수집 순서는 `wat_sources`, `wat_audit`, `wat_review`다. `wat_audit`는 위 자료 외 기존 `/workspace/batch-inputs/us/{filings.pkl,yahoo/}`의 주식 수 공개시점과 분할 입력도 이용한다. 보도 자료·보고서 URL, 원 파일 SHA와 정규화 자료를 보존했다.
