# 153130 원천 적격성 — 부분 확인 / 실증 차단

공식 상품 API, 삼성자산운용 2026-08-31 기준 운용보고서, 공식 가격 XLS 세 건을 실제 확보했다.
정식 명칭은 **삼성KODEX단기채권증권상장지수투자신탁[채권]**, 거래소 코드
153130, 상장일 2012-02-22, 기초지수는 **KRW Cash Index Total Return**이다.
이는 무위험 현금이 아니라 거래소에서 매매되는 국내 단기채권 ETF다.

| 단계 | 판정 | 실제 확인 범위 |
|---|---|---|
| 원천 확인 완료 | 부분 완료 | 공식 상품 신원·상장일·기초지수, 최근 분배금, 가격/NAV 구분·날짜 이력 |
| 파서 검증 완료 | 고정 API 투영 표본에 한정 | 15개 분배 기록, 식별/날짜/금액/중복 오류 격리 |
| 데이터 적격성 검증 완료 | 아니오 | 가격 유효성/달력/무거래 미검증, 전체 분배·배당락·역사 빈티지 미확보 |
| 실제 경제성 실증 가능 | 아니오 | C2 실행·수정 권한 및 총수익/비용 적격성이 별도 필요 |

`source-receipts.json`은 원문 SHA256·바이트 수·취득시각·URL을 고정한다.
원문 JSON/PDF는 작업 scratch 경로에만 보존하고 Git에는 결과 값이 없는 상품
필드 및 분배금의 작은 투영 표본만 넣었다. `issuer-projection.json`은 **원문 자체가
아니며** SHA256도 원문과 다르다. 원격 재조회는 가변적이므로 고정 투영 표본의
오프라인 재현과 원문을 다시 확보하는 작업은 구분한다. 현재 API가 알려주는
상장일은 상장 당시 이용 가능했던 상품 명세의 빈티지를 인증하지 않는다.

실제 API 분배금 표는 2025-08-14~2026-10-15 **지급기준일** 15행이다.
`BASIC_D`(기준일), `PAY_D`(지급일), `DIVID_A`(분배금),
`TAX_DIVID_A`(과세대상액)를 보존한다. 과세대상액은 세후 현금이 아니다.
배당락 기준일 필드는 없어 `exDate=None`으로 유지한다. 지급기준일·지급일에서
배당락을 추정하지 않으며, 이 15행으로 2012년 이후 분배금의 완전성을 주장하지 않는다.
PDF의 "월중 지급"과 현재 API의 "매월 15일 지급기준일"은 현재 안내에 한정된다.

API는 가격, NAV, 수익률 등 다른 섹션도 반환한다. 파서는 허용 필드만 선택하며
가격/NAV/수익률 경로를 출력·평가하지 않는다. PDF 키워드 추출 중 인접한 공개
수익률 표가 한 차례 도구 출력에 함께 나타났고, 이를 표본·설계·계산에 사용하지
않았다. 새 수익률 계산, NAV 평가, C2 귀속 실행은 없다.

추가로 API가 알려준 공식 `excel_standar.do?fId=2ETF35&gijunYMD=20261104`를
**한 번** 조회했다. 736,768바이트 XLS의 표제는 `KODEX 단기채권 기준가격`이고,
거래가격(종가/거래량), 펀드기준가격, 과표기준가가 별도 열이다. **날짜 열과
표제만** 선택해 2012-02-22~2026-11-04의 3,610개 관측 날짜를 확인했다.
`issuer-price-date-projection.json`과 `price-source-coverage.json`에 재현 입력과
요약을 보존했다. 가격/NAV/거래량 숫자는 선택·출력·검증하지 않았다.
따라서 가격 **원천 확보**와 실제 **체결 가능성 검증**을 구분한다. 향후 거래가격의
실제 체결 가능 세션·거래량과 NAV를 별도로 보존하고, 상장일부터 승인 cutoff까지
공식 거래소 달력과 양방향 대조해야 한다. 무거래/정지 및 가격 공백은 마지막 가격으로
대체하지 않는다. 현물 종가와 분배금을 결합할지, 이미 분배금을 반영한 지수인지
먼저 확인해 이중 분배 반영을 막아야 한다. NAV는 거래소 체결가격 대용이 아니다.

현재 공식 보수 안내는 연 0.150%(지정참가회사 0.001%, 집합투자 0.129%,
신탁 0.010%, 일반사무 0.010%)다. 과거 요율 이력은 확인하지 않았다.
펀드 비용이 반영된 NAV/거래가격 기반 수익에서 같은 운용보수를 다시 차감하면
안 된다. 투자자 수수료·호가 스프레드·슬리피지·세금은 별도 항목이며,
현재 표시 보수만으로 과거 총비용이 확정되지 않는다.

공식 API의 현재 일반 과세 안내는 매매차익과 분배금 각각에
`Min(매매차익 또는 현금분배금, 과표 증분) × 15.4%`를 제시한다.
투자자 계좌·거주·계좌유형·과거 세법에 따라 적용이 달라져 투자자 계약 및
시점별 공식 세법 확인 없이는 세후 수익에 적용하지 않는다. 유동성/수수료
측정값, 역사 요율, 내부 연구·재배포 권리도 미확인이다.

#317 `economics.py`의 `reconcile_distribution_events`, `total_return_input_gate`를
읽기 전용으로 검토했다(고정 SHA `a3ee7a716e56c97c99b02537ac060aca01bdb038`).
전자는 증권·기준·배당락 증거의 일치를, 후자는 전체 분배·기업행동·가격 기준을
요구한다. 현재 표본은 이 조건을 만족하지 않아 호출해 통과를 주장하지 않는다.
해당 코드나 별도 총수익 계산기를 복사하지 않았다. #317의 기존 issuer adapter는
069500 전용이므로 153130을 거짓 신원으로 넣어 재사용하지 않는다.

Opus 인계: 153130은 기존 세 현금 가정과 별도로 검토할 **상품 신원 확인된
후보**다. 다음 좁은 승인 범위는 전체 분배/공식 배당락/거래가격·거래량과
시점별 비용·권리 증거의 확보다. 이 공백을 해소하기 전에는 C2 계약의 현금
가정에 추가하거나 투자 가능한 대조군으로 승격하지 않는다. 기존 C2 등록
계약은 수정하지 않았으며 통계 가설·Phase D 예외도 승인하지 않았다.
