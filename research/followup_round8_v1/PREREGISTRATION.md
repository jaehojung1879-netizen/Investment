## A. 미국 — 펀드 공시가 시총·업종보다 더 알려주는가

### A1. 판단일 이후 자료 유입 점검과 정정 (`us_audit.py`)

#347 코드를 읽어 찾은 후보 세 가지다. 각각의 크기를 먼저 재고 고친다.

| ID | 위치 | 문제 | 정정 |
|---|---|---|---|
| L1 | 벤치마크(`sample.build`, `evaluate_us.filing_active`) | 펀드 보고일 이전의 최신 IVV 보고를 고를 때 IVV 공개일을 보지 않았다. IVV가 펀드보다 늦게 공개되면 판단일에 없던 IVV 보유가 쓰인다. | IVV 보고 중 **IVV 공개일 ≤ 펀드 공개일**인 것만 쓴다. 보고일 ≤ 펀드 보고일, 100일 이내 조건은 그대로다. |
| L2 | 종목 식별자(`sample.cusip_map`) | CUSIP → 티커 표를 전 기간 제출에서 한 번에 배웠다. 나중 제출에서만 보인 짝이 과거 보유 연결에 쓰이고, 나중에 티커가 둘이 된 CUSIP은 과거에도 버려진다. | 펀드 공개일 F 이전(≤ F) 제출에서 관측된 (CUSIP, 티커) 짝만 쓴다. F 시점에 짝이 하나면 연결, 둘 이상이면 버린다. 보고된 티커 필드의 직접 일치는 그대로다. |
| L3 | 중복 펀드 제거(`sample.build`) | 같은 보고일 복제 판정에서 순자산이 가장 큰 펀드를 남겼다. 남긴 쪽이 늦게 공개되면 먼저 공개된 쪽이 판단일 이후 자료 때문에 빠진다. | 같은 보고일 안에서 공개일 순서로 본다. 이미 공개된(≤ 자기 공개일) 유지 펀드와 코사인 ≥ 0.95면 복제로 뺀다. 먼저 공개된 쪽이 남는다. |

**보고할 세 단계**

1. **O (원래)**: #347 B 재현
2. **C1 (같은 날짜·같은 표본의 정정 값)**: #347 표본 제출과 같은 신호일에서, L1·L2만 정정한 초과 보유로 다시 계산한다. 정정 IVV가 없어 초과 보유를 계산할 수 없는 제출은 신호에서 빠지고, 그 수를 센다.
3. **C2 (정정 후 전체 적격 표본)**: L1·L2·L3을 모두 정정한 채 심사(액티브 셰어 포함)와 복제 제거를 다시 해서 만든 표본의 모든 신호일

- 공통 표본 효과 = C1 − O(같은 날짜)
- 표본 효과 = C2 − C1(공통 날짜)과 C2 전체 날짜

### A2. 같은 판단일·후보군·종목 수 비교 (모두 기존 가격+사업 확인 `PRICE_CONFIRMED` TOP5, 업종당 2개, 동일가중)

| ID | 후보군 |
|---|---|
| BASE | 전체 적격 모집단(기존) |
| CAP | 시총 백분위 ≥ 0.5(시총만 쓰는 기존 대조군) |
| OW | `OW_BREADTH` 백분위 ≥ 0.5(#347 B, 공시 필터) |
| **OW_RESID** (신규, 이번에 고정) | 같은 업종 × 업종 내 시총 3분위(기존 `capTercile`) 칸 안에서의 `OW_BREADTH` 백분위 ≥ 0.5. 업종·시총을 맞춘 공시 필터다. |
| OW_CTRL / BASE_CTRL / CAP_CTRL | 각 책의 종목마다 같은 업종에서 시총이 가장 가까운 비보유 종목(날짜당 한 번 사용) |

- 매칭이 모두 된 날짜만 대조군 비교에 쓰고, 매칭 가능 날짜 비율을 표시한다.
- 고정 기준: 기존 칵테일, U1, SPY 총수익, QQQ(보조)
- 비용: 고정보유 `evaluate.net`, 장부 `us_decision_pilot.simulate`(#347과 같음)

### A3. 평가

- **고정보유**: 6·12개월 주간 코호트, 비용 차감 순차이, 이동 블록 95%(블록 H/5주), 실제 코호트 수와 독립 블록 수
- **장부**: L26·L52 연복리 차이, IR, TE, MDD, 연 비용, 회전율
- **국면**: 진입 < 2023-01-03 / ≥ 2023-01-03(#346·#347과 같음)
- **대형 기술주 기여**
  - 고정 목록: AAPL, MSFT, NVDA, AMZN, GOOGL, GOOG, META, AVGO, TSLA
  - 각 코호트의 Σ(비중 × 보유기간 수익)을 낸다. 공시 책과 대조 책의 차이 중 이 종목들이 차지한 몫을 보고한다.

### A4. 판정 (정정 후 전체 표본 C2, 6개월 FULL, Holm 3개)

| 주장 | 차이 |
|---|---|
| P1 | OW − CAP |
| P2 | OW_RESID − BASE |
| P3 | (OW − OW_CTRL) − (BASE − BASE_CTRL) |

- **주장별**: Holm 단측 p < 0.05이고 두 국면 모두 > 0이면 `SUPPORTED`, 유의성만 빠지면 `DIRECTIONAL_ONLY`, 그 외는 `NOT_SUPPORTED`다.
- **"공시가 시총·업종을 넘어 알려준다"**: P2 또는 P3이 `SUPPORTED`일 때만 그렇다고 결론 낸다.
- **"운용 장부가 SPY를 이겼다"**: 6개월 SPY 대비 평균의 95% 하한 > 0이고 L26 연복리 차이 > 0일 때만 그렇다고 결론 낸다. 책마다 따로 보고한다.
