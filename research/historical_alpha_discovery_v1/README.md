**결과: 안정적인 추가 알파를 발견하지 못했다. 실제 분석과 ETF 비교는 수행했다.**
이전에 노출된 역사를 사용한 `EXPLORATORY_ON_PREVIOUSLY_EXPOSED_HISTORY`다.
검증된 추천, 독립적인 OOS, production 신호가 아니다.

소유자의 2026-10-24 새 탐색 지시에 따라 독립 연구를 시작했다. 기존 Phase D
종료 결정·봉인 결과·C1 승인/실행·#277/#278의 규칙이나 기록은 변경하지 않았다.
모든 변경은 이 디렉터리에만 있다. 기존 연구 실행기를 import하거나 호출하지 않는다.

## 실제로 새로 계산한 것

가설: **같은 양(+)의 12-1 모멘텀 상위 삼분위 안에서, 최근 126세션의
장중 누적 수익이 높은 종목이 단순 종가 모멘텀 선택보다 유용한가?**
장중 누적 로그수익 `sum(log(close/open))`과 야간 귀속
`log(close[t]/close[t-126])-intraday`를 구분한다. 기존 OHLCV의 새로운 표현이며
독립적인 새 원천 정보라는 주장은 하지 않는다. 기존 Atlas의 월별 모멘텀 지속성이나
장중 고저 범위·거래량 변수와 동일한 검정을 다시 실행하지 않았다.

- 고정 책: ETF 단순 보유, 모멘텀 5종목, 장중 귀속 5종목, 야간 귀속 5종목,
  장중 책 50%+ETF 50%. 업종당 최대 2개, 부족한 20% 슬롯은 ETF.
- 신호 직전보다 엄격히 오래된 Top120 모집단, 253개 연속 KRX 관측,
  신호까지의 기업행동 의심 구간 제외, 60세션 중간 거래대금 proxy 10억원 이상.
- 전일 신호 → 다음 개장 세션 **종가** 체결. 126/252세션 비중첩 보유.
  2014-02-03 고정 원점. 데이터 끝은 사전 선택한 2026-08-31이며 마지막 완성 블록은 2026-06-01.
- 편도 수수료+반스프레드 11.5bp, 날짜별 KOSPI 매도세, 2배 비용 민감도.
  투자금 5천만원 시작·슬롯 현금에 진입 비용 포함·거래대금 1% 한도.
  후보 책은 매 블록 청산/재진입, ETF 대조군은 기간 처음·끝에만 거래한다.
- 학습·튜닝 없음. 2019년까지와 21세션 이상 엠바고 이후의 2020년 이후를
  따로 계산한다. 개발 경계를 걸친 블록은 분리 비교에서 제외한다.
  역사에 이미 노출됐으므로 이 구분을 독립 확증으로 부르지 않는다.

명세·코드는 신규 결과 계산 전에 `dc73bae`에서 고정했다. 이후 run.py 변경은 포맷과 passive ETF 중간 블록의 회전율 집계 수정뿐이며
선택·수익률·비용·경로 판정은 바꾸지 않았다. pinned 런타임 재실행의 금융 결과 차이는 **0**이었다.
별도 `diagnostics.py`는 실행 후 기술 진단이며 선택·기간·수익 판정 규칙을 바꾸지 않는다.

## 결과

종목·시점·기간 라벨 **3,626개 중 3,538개**를 계산했다. 중첩 종목 관측을
독립 표본 수라고 주장하지 않는다. H126/H252 유효 종목-시점 수는 각각
2,371/1,167, 비중첩 신호일은 24/12개다. 각 IC는 동일 유효 마스크·최소 30종목을 사용한다.
장중 귀속의 날짜 평균 Spearman IC는 H126 **0.0103**, H252 **0.0243**이다.
이 작은 양의 기술통계는 발견·채택의 근거가 아니다.

장중 책 − 모멘텀 책의 유효 쌍별 비용 차감 수익 차이:

| 기간 | 예정/유효 쌍 | 평균 블록 차이 | 연도 군집 부트스트랩 기술 95% 구간 |
|---|---:|---:|---:|
| H126 | 24 / 19 | +1.99%p | −8.41 ~ +16.69%p |
| H252 | 12 / 7 | +0.44%p | 유효 쌍 부족으로 미계산 |

전체 유효 쌍만의 결과이며 투자 가능한 연간 수익률이 아니다. H126 개발/후기 구간의
평균 차이는 −3.55/+11.23%p, H252는 +2.26/−7.63%p다. 표본과 방향이 안정적이지 않다.
모든 비교의 실제 분모와 차단 사유를 JSON에 보존했다. 유효 쌍이 2개뿐인 104개
cohort를 충분한 증거로 인정하지 않는 합성 회귀 테스트도 있다.

**끝까지 연결 가능한 사전 지정 대조군**은 아래와 같다. 주 가설의 장중 책이 아니다.
같은 2020-03-30~2026-06-01, H252 6블록·1,512 일간 관측, 기본 비용:

| 책 | 비용 차감 proxy CAGR | Sharpe (rf=0) | MDD | 일간 CVaR95 |
|---|---:|---:|---:|---:|
| 069500.KS 단순 보유 | 36.45% | 1.449 | −34.33% | −3.29% |
| 야간 귀속 최대 5종목 | 28.28% | 0.870 | −43.03% | −4.88% |

연평균 CAGR 차이는 **−8.17%p**, 산술 연환산 수익 차이는 **−2.22%p**다.
차이를 모두 종목 선택 효과라고 부르지 않는다. 변동성·복리 효과가 함께 있다.
야간 책의 연 하방편차는 24.88%, ETF는 15.97%다. 비용을 두 배로 한 결과,
연도별 수익, 회전율·비용, 모든 책과 기간은 `results/portfolio-summary.csv` 및 JSON에 있다.

주 H126 장중 책은 24블록 중 4개가 차단되어 **전체 기간 CAGR·Sharpe·MDD는 null**이다.
002790/090430의 2015년 정지 각 10세션, 009830의 2023년 정지 23세션,
012450의 2024년 정지 **18세션**, 006800의 미해결 가격 기준이 해당한다.
정지 중 NAV를 관측된 거래 가격처럼 인정하지 않는 보수적 계약이다.
정지 자체가 종결 손실을 뜻하지는 않는다. 분할·분배 권리와 재개 가격 기준의 별도
연결 없이는 임의 보간·종결 0원·마지막 가격 청산·유효 블록 이어붙이기를 하지 않았다.

## 지금 가능한 데이터와 남은 한계

- 원시 일봉: 2013~2026년, 저장된 종목 수는 연도별 467~569개.
  이는 KOSPI 전체의 완전한 가격 모집단이 아니다. 날짜별 Top120에 한 번이라도
  속한 종목은 260개다. 연도별 날짜·관측 수는 진단에 있다.
- H126 예정 2,880 종목-시점 중 2,419개가 특징 적격이다(84.0%).
  제외 이유는 세션 결측/무거래 157, 기업행동 의심 121, 우선주 휴리스틱 96,
  업종 미분류 81, 유동성 6개다. 결측을 0이나 행 삭제 후 짧은 관측 창으로 바꾸지 않았다.
- DART candidate 저장소는 FY2015~2026에 연 700~970건(2026년 483건),
  176~244종목 범위다. FY2014 shard는 부재다. 늦은 정정 공시가 있으므로 fiscalYear로
  과거에 소급하면 안 된다. 이 실험은 재무 특징을 사용하지 않았다.
  계정별 관측률과 실제 availableFrom 범위는 `diagnostics/diagnostics.json`에 있다.
- 외국인/기관 수급 manifest는 2026-09-24 `REFUSED: HTTP 400 LOGOUT`,
  해당 수집 실행 기록 0건이다. OHLCV로 투자자 수급을 대체하지 않았다.
- 종목 수익은 저장된 split-continuous **부분 배당** 누적 지수다. ETF는 기존 외부 대조를
  통과한 총배당 지수다. 따라서 완전히 대등한 주주 총수익·세후 계좌 성과가 아니며,
  전체 종목의 기업행동·지급 내역을 새로 인증하지 않았다. 소수 주식 단위,
  종가 체결과 배당 재투자도 가정이다. 업종은 과거 재구성이고 원천 revision 빈티지는 미인증이다.
- Strict 표본의 모집단/특징 선택은 과거 시각을 따르지만 경제적 경로 전체가 PIT 인증된 것은 아니다.
  종료 22종목+006800을 제외한 **생존자 조건부 표본**을 별도 계산했다.
  그 표본에서도 H126 장중 책은 완성되지 않았고, H252 야간 대조군 CAGR은 27.16%다.
  미래 생존 신원 제거로 결과를 정상적인 실전 백테스트처럼 제시하지 않는다.

**다음 한 작업:** 전체 데이터 수집이나 새 모델 대신, 이 고정 책이 실제 선택한
정지 종목의 분할·분배 권리와 가격 재개 연결을 기존 보존 원천에서 확인한다.
새 버전의 독립 가격 어댑터로 검증하고, 기존 봉인 원천은 수정하지 않는다.
그 전에는 현재 종목 추천이나 실사용 승격을 하지 않는다.

## 재현과 검증

출발 main `591f182955ab85bc527ddedc41c2d77d1fd24eaa`,
입력 `signal-history@a0a31895699aacaf3f8f30401b348703e39088b7`.
원천 파일 SHA-256과 런타임은 `summary.json`, 최초 실행·재현 대조는 `execution-log.json`.
실험에는 저장된 Git 데이터만 사용했다. 신규 데이터 공급자 호출·유료 서비스 사용 없음.

```bash
python -m venv .venv-discovery
.venv-discovery/bin/pip install -r requirements.txt -r requirements-dev.txt
git fetch --depth=1 origin a0a31895699aacaf3f8f30401b348703e39088b7
.venv-discovery/bin/python -m research.historical_alpha_discovery_v1.run --output /tmp/discovery-reproduction
.venv-discovery/bin/python -m pytest -q research/historical_alpha_discovery_v1/test_discovery.py
# Optional post-execution diagnostics, after results exist at the default study path:
.venv-discovery/bin/python -m research.historical_alpha_discovery_v1.run
.venv-discovery/bin/python -m research.historical_alpha_discovery_v1.diagnostics
.venv-discovery/bin/python -m research.historical_alpha_discovery_v1.tables
```

실행 노트북은 `analysis.ipynb`. 저장된 결과·그림·독립 복리 대조 30개를 포함하며
위에서 아래까지 오류 없이 실행했다. 노트북 재실행에는 nbformat 5.11.1, nbclient 0.11.0,
ipykernel 7.4.0, matplotlib 3.10.8을 별도 설치한다. 최초 런타임과 pinned 패키지 재실행의 금융 차이는 0,
30개 완성 NAV의 독립 복리 대조 최대 오차는 8.1e-10 미만이다.
합성 테스트 19개, 전역 ruff, compileall, 별도 /tmp seed 생성·검증을 통과했다.
**전체 pytest는 실행하지 않았다:** 실제 봉인 KR 결과를 재계산하는 기존 테스트가 있어
이번 지시의 봉인 연구 재실행 금지와 충돌한다. 원 테스트와 워크플로는 변경하지 않았다.
GitHub CI 상태는 실제 원격 HEAD의 결과로 별도 확인해야 하며 로컬 통과를 대체하지 않는다.
