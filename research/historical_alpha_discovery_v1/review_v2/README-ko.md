# KR 발견 연구: 제출 전 측정 검증 v2

기준 main `591f182955ab85bc527ddedc41c2d77d1fd24eaa`, 원 연구 HEAD `347d186f91b775e6d9cb65fdcd0d99e9687fe331`.
이 폴더는 **결과를 본 후의 별도 측정 감사**다. 원 연구의 코드·명세·결과 50개 파일은 byte hash 그대로다.
봉인 연구 실행기를 호출하지 않고 기존 저장 원천만 읽었다. 선택·기간·임계값·보유종목·결측 정책을 바꾸지 않는다.

`plan.json`은 실제 endpoint 계산 전에 다섯 차단 종목 전체와 처리 원칙을 고정했다.
`audit-result.json`에는 실제 원천 SHA, 보존 DART section의 URL/본문 SHA/발췌, 분할·정지 검사 및 수치 대조가 있다.

| 검증 | 판정 |
|---|---|
| 원 결과 파일 50개 | SHA 전부 일치 |
| 완성된 NAV 30개 | 달력 연속성·복리·CAGR·Sharpe·MDD·CVaR·하방편차 독립 재계산 일치 |
| 쌍별 비교 | 동일 기간/책/표본/비용의 실제 유효 쌍 수·평균 일치, 작은 표본의 구간 미계산 유지 |
| 특징/PIT | 과거 가격 창·strict-prior 모집단 선택. 산업 재구성·원천 revision은 완전한 당시 PIT 인증 아님 |
| 거래비용 | 현금 예산 안에 진입 비용, 매도세, ETF 최초/종료 비용, 강제 재진입 비용을 검증. 세후 개인 계좌 수익 아님 |
| 수익 기준 | 종목 부분 배당 누적 vs ETF 총배당: 완전한 shareholder total-return 동등성 미확인 |
| 통계 결론 | 추가 알파 입증·추천·승격 근거 없음. 유효 블록만 이어 붙여 전체 수익률을 만들 수 없음 |

**2019 비용 명세의 모순도 발견했다.** 원 spec의 `2019ConservativeFullYear` 키는 연중 30bp처럼 보이지만,
같은 spec note와 최초 결과 전 고정된 실행 코드는 6/3부터 25bp를 사용했다. 본 감사는 실행 코드의 실제
금융 계산을 검증하며 원 spec을 조용히 고치지 않는다. 기존 파일에서 상충하는 키가 있다는 사실을
리뷰어가 함께 판단해야 한다. 25bp를 결과를 본 뒤 유리하게 선택한 것이 아니다.

새 계산은 세 종목의 **해당 원천 기준 단일 보유 종료 가치**뿐이다. 알려진 분배 이벤트 범위를 넘는
배당을 0이라고 주장하지 않는다. 두 인적분할 사례에 유리한 비율·가격·후속 종목을 임의 배정하지 않았다.
기존 원 연구의 24블록 중 4개 차단, 전체 장중 책 CAGR/Sharpe/MDD null은 그대로다.
해당 고정 책을 원천 수정판으로 다시 평가하려면 분배 권리와 전체 mark 정책을 별도 고정해야 한다.
