# industry-ocfyield-conditional-v1 — 결과 없는 검정력 게이트: **NO_GO**

질문: 산업 `MEDIAN_ocfYieldProxy`가 `REL_MOM_126`, PIT 시장 베타, `TOP1_CAP_SHARE`를 통제한 뒤에도 H126
산업−069500 상대수익에 증분 정보를 주는가.

판정 규칙은 [`protocol.json`](protocol.json)에 있습니다(SHA-256 `e20414ab…`). 이 파일은 시뮬레이션 전에 커밋
`2cbf172`로 고정했습니다. 실제 결과·상태·진입/청산 열은 하나도 읽지 않았습니다(`load_inputs`가 거부). 라벨은
합성이며, 실제 610일 × 14산업 격자에서 H126(25주)/H252(50주) 중첩을 달력 위치 그대로 재현합니다.

## 실제 측정된 표본 (입력 열만)

| 항목 | 값 |
|---|---|
| 산업-날짜 격자 | 8,540 (610일 × 14산업) |
| OCF·모멘텀·집중도 동시 관측 | 3,613 (42.3%) |
| 상속 최소 단면 8산업 충족일 | **193 / 610** (단면 중앙값 9, 최대 11) |
| 충족일 연도 분포 | 2017:11, 2018:2, 2019:43, 2020:53, 2021:11, 2022:42, 2023:21, 2025:10 |
| 충족일 0인 연도 | 2015, 2016, **2024**, 2026 |
| PIT 베타 | 패널에 없음. 채우지 않음(K2는 상한, K3는 합성 지속 통제로 자유도만 소모) |
| 귀무 하 유효 독립 날짜 | H126 15.0, H252 9.7 |

## 결과 (2,000회, seed 20261031, 일측 SN, Holm 1단계 α=0.025)

| 설계 | 크기(명목 2.5%) | ρ=0.10 검정력 | ρ=0.136 | 80% 검출 최소 ρ |
|---|---:|---:|---:|---:|
| H126 K2 IID (판정 셀) | **4.6%** | **23.0%** | 33.3% | 0.30 |
| H126 K3 IID | 4.5% | 21.6% | 32.6% | 0.30 |
| H252 K2 IID | 6.2% | 19.1% | 25.4% | 0.40 |
| 완전 관측 시나리오(사후 진단, 판정 입력 아님) | 2.8% | 39.5% | 61.3% | 0.20 |

- 판정 셀의 검정력 23.0%(459/2,000, Wilson 95% MC 구간 약 21.2–24.8%)는 상한까지 포함해도 하한 80%에 크게
  못 미칩니다. NO_GO의 근거는 이 조건 하나로 충분합니다.
- 크기 4.6%(92/2,000, Wilson 약 3.8–5.6%)도 상한 3.75%를 넘습니다. 따라서 이 희소·단절 표본에서 등록 SN
  검정의 보정은 검증되지 않았습니다. 다만 이 조건은 NO_GO에 필요하지 않습니다.
- K2는 실제 마스크와 실제 특성·통제값 위에서 설계 중 가장 유리합니다(베타 통제·결과 유효성 마스크는 표본과
  자유도만 줄임). 그러나 모든 진짜 시장 과정에 대한 **수학적 상한은 아닙니다**. 검정력은 실제 비중심성과 단면
  의존 구조에 좌우되며, 그것은 이 시뮬레이션이 정한 DGP일 뿐입니다.
- 완전 관측 시나리오(14개 산업 × 610일 전부, 특성·통제를 AR(1) 합성으로 대체)는 **넉넉하게 지정한 DGP
  시나리오**입니다. 상한이 아니며, 데이터 복구나 다른 가설이 결코 도움이 안 된다는 증명도 아닙니다. 이 시나리오에서도
  ρ=0.10 검정력은 39.5%입니다. 그러므로 KR22·KSIC 복구를 *이 질문*의 근거로 삼을 이유는 약합니다.
- 기존 주변 IC +0.136을 그대로 조건부 효과로 가정해도 검정력은 33%입니다.

## 결론

등록된 `industry-ocfyield-conditional-v1`은 `NO_GO`입니다. 실제 결과는 읽지 않았고 읽을 필요도 없습니다. 이
연구를 위한 베타 구축과 실행은 하지 않습니다. 같은 KR 14산업 단면에서 같은 질문을 다시 세우지도 않습니다(36셀
산업 연구 신설, 봉인 이력 재실행 포함). 프로토콜의 `noRescue`에 따라
기간·최소 단면·특성·통제·검정·임계값은 바꾸지 않습니다.
